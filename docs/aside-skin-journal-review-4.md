## 🧪 연습 모드

기록 화면 **맨 위** 노란 띠 「🧪 연습 모드 — 예시 기록이에요 · 저장·사진·상담이 실제로 안 나가요」가 보여야 한다. **안 보이면 즉시 멈추고 "띠 없음" 보고.**
⚠️ 새로고침(⌘R) 금지 — 연습 기록이 처음으로 돌아간다. 이동은 앱 안 버튼으로만.

### 🚨 절대 금지
- **홈 화면**의 하트·범프·기분·선물·퀵메시지 바(꼼이 폰에 진짜로 간다). 홈에서는 「피부 일지」 카드만 누른다.
- 피부 일지 밖 화면에서 쓰기·보내기, 로그아웃, `?practice=1` 빼기, 사진 파일 고르기.
- **「힘든 날 우댕에게 알리기」 스위치는 직접 누르지 마라**(아래 1번은 저장 막대만 누른다).

창 크기: 휴대폰 폭 390×844(흉내) 위주, 마지막에 컴퓨터 크기 한 번.

## 확인할 것 (3차에서 걸린 것 → 고친 것)

1. **스위치 겹침**(3차 F🚨): 기록 화면을 스크롤해 「힘든 날 우댕에게 알리기」 스위치가 아래 저장 막대와 **겹치는 위치**로 맞춘 뒤, 저장 막대의 **오른쪽 끝(스위치가 비치는 자리)**을 누른다 → **저장만 되고 스위치는 그대로**여야 한다(스위치 색이 바뀌면 걸림).
2. **약 기록이 지워지지 않음**(3차 TOP1): 오늘(21일) 약 줄: 이름 「항히스타민」 그대로, 용량 「2알」, 시각 「09:00」, 「먹음」 → 저장. 오른쪽 위 「상담」 → 「✨ 오늘 상담 정리하기」 → 정리 화면.
   - 약 후보(3알 · 23:00 · 늦게)에 **「일지와 다름」이 안 떠야** 한다(시각이 달라 따로 먹은 것으로 봄).
   - 반영 → 완료 화면에 **무엇이 어느 날 들어갔는지 목록**과 「기억 n개를 남겼어요」가 보이는지 → 「일지에서 보기」 → 21일 약이 **두 줄**(2알·09:00·먹음 + 3알·23:00·늦게)인지.
3. **버튼 칩**: 정리 화면 아래 버튼에 「일지 n · 기억 n」이 따로 보이고, 후보·기억을 켜고 끌 때 숫자가 맞게 바뀌는지.
4. **다시 보기**(3차 C5): 상담 화면으로 와서 「오늘 정리 다시 보기 ✓」 → **반영한 값 그대로**(고친 용량·고른 날짜), 켜기/끄기·바꾸기/메모로만 버튼이 **안 보이고**, 아래 「이 날 정리는 일지에 반영했어요…」.
5. **화면 갇힘**(3차): 정리 화면 ← → 상담, 상담 ← → **기록 화면**(정리로 다시 가면 걸림). 몇 번 오가도 기록 화면으로 빠져나오는지.
6. **단위·안내**: 정리에서 「잠 — 5.5시간」을 켜고 「어제」를 고르면 「현재 일지: 7시간」처럼 **단위**가 붙는지. 날짜를 안 고른 채 켜면 아래 빨간 안내가 **바탕이 있는 알약**으로 떠서 다른 글자와 안 겹치는지. 정리 기다리는 동안(「다시 정리」를 눌러 보면 1~2초) 왼쪽 위 ← 가 있는지.
7. **분석**: 의심 요인 표에 **「술 · 평균 0.0」이 없어야** 한다(점수 안 적은 날은 평균에서 뺌). 30일 그래프 범례 「기록 없음」 동그라미가 **하나**인지.
8. **저장 막대**: 값을 하나 바꿔 「아직 저장 전이에요」가 떠도 막대가 커지지 않아 약 버튼을 덜 가리는지. 지난날을 고르면 「그날은 증상 없음」인지.
9. **달력 사진 표시·우댕 폰**: 범례에 카메라 모양 「사진」이 한 줄 안에 있는지. `?practice=1&view=1`(모든 확인 끝난 뒤)로 기록 화면 사진 칸이 「이 날 올린 사진이 없어요」인지. 끝나면 `&view=0`.
10. **컴퓨터 크기**: 정리 화면이 가운데 칸으로 보이는지(전체 폭으로 늘어나지 않는지).
