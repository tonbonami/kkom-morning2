
## 봉투 — 고칠 점 (네가 준 EnvelopeReveal·ThoughtBubble 을 실제로 돌려 보니)

아래 네 가지를 고친 **`EnvelopeReveal.tsx`·`ThoughtBubble.tsx` 두 파일 완성본만** 다시 줘(props 이름·타입은 그대로, 성능 규칙도 그대로: transform·opacity 만 움직이기, 무한 반복 금지).

1. **내용 없는 종이가 처음부터 봉투 전체를 덮는다.** 종이(`z-10`)가 봉투 껍데기 래퍼의 형제로 밖에 있고, 래퍼는 `will-change-transform` 때문에 자기만의 겹침 순서를 가져서, 종이가 래퍼 통째(앞판·덮개·밀랍·「From. 꼼이」)보다 위에 그려진다. 닫힌 봉투인데 종이 판만 보이고 덮개·밀랍·이름이 안 보인다.
   → 겹침을 바로잡아: 뒷판(안감) < 종이 < 앞판 포켓 < 닫힌 덮개. 덮개가 90도를 넘어 젖혀진 뒤엔 종이가 그 앞으로 올라와야 한다. 봉투가 빠지며 사라질 때 종이는 계속 올라가 남아야 한다.
2. **젖혀진 덮개가 칸 위로 튀어나온다.** 덮개 높이(봉투의 52%) 만큼 위로 펼쳐져 이 컴포넌트 바깥 위쪽(실제 읽기 창에선 머리 줄)을 덮는다. 컴포넌트 안에서 공간을 확보하거나(위 여백 ≥ 덮개 높이) 덮개가 안 나가게.
3. **`bg-white/92` 는 이 프로젝트(Tailwind 3.4)에서 CSS가 안 생긴다**(투명도는 5 단위만) → 생각풍선이 투명하다. `bg-white/90` 이나 `bg-white/[0.92]` 로(풍선 본체·꼬리 방울 2개).
4. **끝 → 진짜 편지로 넘어갈 때 튀지 않게.** `opened` 가 되면 이 컴포넌트가 사라지고 같은 자리 맨 위에서 실제 편지지(폭 꽉 참, 모서리 28px, 바탕 = `palette.paperPreview`)가 나온다. 마지막 장면의 종이가 그 자리·크기·모서리에 최대한 가깝게 끝나게 해 줘(작은 사각형이 위로 휙 사라지고 큰 편지지가 뚝 나타나면 안 된다).

코드 블록 두 개만, 설명은 맨 끝 2줄. 주석은 짧게.
