> 2026-10-15~16, 꼼모닝 세션 정리. 사이담의 카피바라 작업용.
> 우댕 말: *"돼지 오늘 너가 잘해서 이번엔 카피바라로 만들고 싶은데, 우리가 쓸건 아니고, 사이담에서 쓸거야. 카피바라가 그런 이미지인건 알지. 머리위에 오리 앉아도 평온하고, 누가 괴롭혀도 화 안낼것 같은 그런 짤들이 있대. 그런것을 추구미로 삼는 분이 있어서 선물해 드리려고."*

결과물 참고: 꼼모닝 `art/kkuldaeng/` (디자인 시안·16종·기분 12종·움짤 원본), `public/emo/kkuldaeng/`, 움짤 `public/emo/sai-anim/kkul-*.webp`.

## 1. 캐릭터 디자인 — 두 번 틀리고 세 번째에 맞았다

| 시도 | 한 것 | 우댕 반응 | 배운 것 |
|---|---|---|---|
| 1차 | 사람처럼 앉은 아기 + 큰 돼지 코 + 꿀벌 후드 | "너무 돼지인데 ㅎㅎ 귀여워야지" | 이목구비가 얼굴 전체에 퍼지면 진짜 동물처럼 보인다 |
| 2차 | 코·눈을 콩알만 하게 + 큰 모자 속 작은 얼굴 | "비율이 돼지가 아니잖아. 베이브 같은 돼지지만 귀엽게. 일반적으로 귀엽게 보이는 돼지 얼굴 있잖아" | 귀엽게 만든다고 **동물 비율을 버리면 안 된다**. 모자가 머리 모양을 가리면 무슨 동물인지 안 보인다 |
| 3차 ✅ | **진짜 아기돼지 비율·자세**(네 발, 앞으로 나온 둥근 코판, 세모 귀, 꼬불 꼬리) + 옷은 **몸에만**(반려동물 옷처럼) | A(네 발로 서기)·C(배 깔고 엎드리기) OK, B(꼼이처럼 앉기) "자세가 이상해" / "얼굴은 가리지마. 옷만 꿀벌옷이야" | **그 동물이 실제로 하는 자세**로. 다른 동물(강아지) 자세를 빌려 오면 어색하다 |

핵심: 꼼이(푸들)도 사람처럼 앉은 게 아니라 **진짜 강아지 자세**다. 캐릭터 = "진짜 동물 비율 + 흔히 귀엽다고 하는 그 동물 얼굴 + 수채화로 부드럽게".

**카피바라에 옮기면:** 통통한 원통 몸, 네모난 큰 머리, 작은 귀, 반쯤 감긴 듯한 무심한 눈, 짧은 다리. 자세는 카피바라가 실제로 하는 것 — 식빵처럼 앉기, 배 깔고 눕기, 물(온천)에 몸 담그기. 사람처럼 두 발로 서거나 손 쓰기 ❌.
⚠️ 유명 카피바라 캐릭터(상품화된 것)를 따라 그리지 말고 **오리지널**로. 사이담은 공개 앱이다.

**고르는 방식이 잘 먹혔다:** 3안을 그려 **기존 캐릭터(꼼이) 옆에 나란히 크림 배경**에 놓고 보여 줌 → 우댕이 고르거나 섞음("A·C 둘 다 괜찮아"). 고른 그림 2장을 이후 모든 그림의 **기준 그림(참고 이미지)**으로 계속 붙였더니 16장 내내 얼굴이 안 바뀌었다.

## 2. 정지 이모티콘 16종

**무엇을 그릴지 — 데이터 먼저, GPT와 상의.**
- 꿀됑은 우댕이 꼼이에게 보낸 메시지 2,049개를 주제별로 셌다(애칭 394·ㅋㅋ 185·사랑해 155…). 원문은 GPT에 안 보내고 **횟수만** 보냈다.
- GPT(Codex `codex exec -s read-only`)에 초안 16개를 비판해 달라고 했더니 내가 빠뜨린 **"응응"(53회)**을 짚었고, 겹치는 것(뽀뽀↔사랑해·꼬옥)을 빼 줬다.
- 카피바라는 받는 분 대화 데이터가 없으니 **"카피바라 짤" 밈**을 조사해서 그 정서(무념무상·평온·괴롭혀도 무표정)로 16개를 짜면 된다. 예: 머리에 오리, 머리에 귤/유자 얹고 온천, 비 맞아도 평온, 볼 꼬집혀도 무표정, 등에 친구들이 줄줄이, "괜찮아", "그럴 수 있지", "평온", "그냥 있음".

**그리는 법 (Codex 이미지, 4장씩 4번):**
- 프롬프트 앞부분(공통 블록)을 매번 똑같이: 캐릭터 설명 + 눈 규칙("ONE SOLID FLAT SHAPE … EXACTLY ONE small white highlight, no eye whites/irises/eyebrows/eyelashes") + **위 22%는 빈 초록**(글자 배지 자리) + 소품은 불투명·초록 금지 + 글자 금지 + 138px에서 읽히게(큰 실루엣 하나, 표정 하나).
- 기준 그림 2장을 `--ref`로.
- ⚠️ zsh에서 `--expect` 목록을 변수에 담으면 안 쪼개져 **그림이 0장** 나온다 → 배열 `"${exp[@]}"`.
- 다 나오면 **138px로 줄여서** 보고 거른다. 다시 그린 것: "사랑해"(날개 하트 개그가 빠짐), "괜찮아?"(반창고가 얼굴에 붙어 다친 것처럼 보임).

**투명 + 글자:**
- ⚠️ **노랑이 들어가면 사이담 `make-transparent-emo.mjs`(despill)를 쓰면 안 된다** — despill이 G를 (R+B)/2로 깎아 **노랑이 살구색**이 된다(꿀벌 조끼·노란 반짝이 다 당함). 대신 `초록 정도 = G − max(R,B)`만큼만 알파를 빼고 그 픽셀만 G=max(R,B)로 누르는 키잉. 꼼모닝 `art/kkuldaeng/set16/make_sticker.py`. 카피바라에 귤·유자·오리(노랑) 들어가면 같은 문제.
- ⚠️ **주아체(Jua)에 없는 글자가 있다** — "꼼슌아"의 '슌'이 □로 깨졌다. 배지에 넣기 전 글꼴 cmap 확인. (꼼모닝은 '순'의 ㅜ 세로획을 둘로 나눠 ㅠ를 만들어 씀 — `syun.py`.)
- 배지 규칙은 사이담 `add-emo-label.mjs` 그대로(잉크 #64493D, 흰 테두리 0.05, 위 24% 띠, −4°).

**크기 맞추기:** 전신은 발바닥 위치·간격으로, 얼굴만 있는 기분 아이콘(12종)은 **피부 면적**으로 맞췄다(어깨 폭 기준은 잘린 위치가 제각각이라 실패).

## 3. 움짤 (Kling) — 이게 제일 많이 틀렸다

### 이야기가 먼저
- 3차 「힘내」는 "준비 → 주먹 번쩍" 동작뿐이라 우댕: *"그렇게 귀엽지가 않아. 폭죽은 폭죽터졌을 때 귀 팔랑거리는 것까지. 예상 못한 행동에 꼼이랑 나랑 빵 터졌는데. 이건 뭐 너무 평범해."*
- 그 뒤 전부 **예고 → 원인 → 과한 반응 → 멍한 마무리**로 짰고 다 OK 받음: 털 펑(힘주다 털이 팝콘처럼 부풂), 콧방울 펑, 귀로 하트, 으악(날개 붕붕 공중부양), ㅋㅋㅋ(콧구멍 푸흡 → 발라당).
- **카피바라는 반대 방향이 웃음 포인트**: 주변은 난리인데 카피바라만 **안 움직인다**. 오리가 머리에 앉음 → 하나 더 → 셋이 탑 → 카피바라는 눈만 한 번 천천히 깜빡. Kling은 뭐든 움직이려 들어서 **"Kkapy stays perfectly still; ONLY the ducks move; at the end one slow blink"**처럼 '안 움직임'을 세게 써야 할 것.

### 만드는 법 (영상 셋을 고리로)
1. Codex로 키프레임 3장(① 시작 ② 절정 ③ 마무리). 정지 16종 중 하나를 ②로 재사용하면 빠르다.
2. **세 장의 기준점을 픽셀로 맞춘다**(발바닥 간격·바닥선). 크기가 다르면 Kling이 **확대(줌)**로 읽는다.
3. Kling VIDEO 3.0, **시작 그림 + 끝 그림**, 720p · 3초 · **소리 끔** = 영상 하나 18크레딧. ①→② / ②→③ / ③→① 세 개 = 54.
   - ⚠️ 소리가 기본으로 켜져 있을 수 있다(1080p·5초·소리 = 60). 길이도 5s로 떠 있곤 했다.
4. 내가 프레임을 뽑아 **박자 편집**: 지루한 구간 1.5~2배속, 긴 정지 자르기, 이상한 프레임 몇 장 빼기. 이음매는 프레임 차이를 재서 원래 동작 크기보다 작으면 OK.
5. 투명 WebP(12fps, 320px) + 배지.

### Kling 버릇 (우리가 실제로 당한 것)
- **시작 그림 한 장만 주면** 1초 뒤 얼굴을 새로 그린다 — 사람 눈(흰자·홍채·눈썹), 벌린 입, 화면 확대. → 반드시 **끝 그림까지** 준다.
- 끝 그림이 **무표정하게 같으면** 앞만 보고 굳은 영상이 된다 → 시작·끝은 **감정이 다른 두 장**.
- **시작 장면을 오래 끈다** — "0.4초"라고 숫자로 박아도 1.3~2.3초. 포기하고 편집에서 자른다.
- "펑"을 순간으로 못 한다 — 0.3~0.4초 동안 녹이듯 쪼그라뜨림 → 편집에서 2프레임만 남긴다.
- 빠른 동작에서 **다리를 사람 팔처럼 쫙** 펴는 프레임, **토끼 귀처럼 곧게 선** 프레임, **입 벌려 혀**가 보이는 프레임이 끼어든다 → 편집에서 뺀다.
- 동물이 옆으로 이동하면 **다리가 5~6개**로 보이는 순간이 생긴다.

### 키프레임 그림에서 내가 놓친 것 (그대로 영상에 옮겨짐)
- 끝 그림에 **발이 6개** → 우댕: *"발이 6개야. 징그러워 죽겠어."* (나는 얼굴만 봤다)
- 귀가 **두 덩어리**로 갈라져 **귀 3개**처럼 보임 → *"귀도 3개?"*
- 귀로 얼굴 덮기 → *"귀도 무슨 빨래짠듯"* (꼬인 귀는 무조건 실패)
- 킁킁 그림에 **분홍 혀**가 그려져 있었음.
→ **얼굴만 보지 말고 다리·귀·더듬이·날개 개수를 매 장 센다.**

### 의뢰서(프롬프트)에 넣으면 잘 먹힌 것
- 캐릭터 문단(개수 명시: EXACTLY FOUR LEGS / TWO EARS …), 눈 문단, 배경 문단("flat green #00B140 … no floor, no shadow, no glow … camera never moves, no zoom").
- 동작은 **번호 박자 + 초**.
- **"Earlier attempts failed: …"** 한 줄 — 지난 실패를 적으면 같은 실수가 줄었다.
- 체크리스트를 Aside에 주고 0·0.5·1·1.5·2·2.5·3초 스크린샷 + 절정 순간 한 프레임씩 세게 함.

### 반투명·초록 함정
- 콧방울·날개·물방울은 **불투명**으로 그리라고 해야 한다(반투명이면 키잉 후 구멍).
- 꽃 줄기·잎·풀은 **초록이라 키잉에서 사라진다** → 갈색 줄기, 잎 없이. 카피바라 온천·물풀 배경 소품도 같은 문제. 물은 불투명 하늘색으로.

## 4. 사람 쪽 규칙 (꼭)
- **단계마다 우댕(사이담에선 Teo) 직접 OK**: 디자인 시안 → 키프레임(크레딧 쓰기 전) → 완성 움짤 → 앱. 내 추천을 "Teo가 정했다"고 전하지 말 것.

- **Aside를 이제 CLI로 직접 부를 수 있다**(우댕이 설치함): `aside session list` → `aside session resume <세션ID> "의뢰서 경로…"`. Teo가 붙여 넣는 중계가 필요 없다. 단 Kling 생성은 Teo "보내" 뒤에만.
