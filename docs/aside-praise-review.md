## 너의 역할

너는 **이 커플 앱을 오늘 처음 받은 사람**이다. 애인이 "우리 둘만 쓰는 앱인데, 여기 칭찬 다이어리 있어. 서로 칭찬해 주는 거야" 하고 깔아 줬다. 아무 설명도 못 들었다. 지금 너는 **우댕** 계정이고, 애인은 **꼼이**다.

## 현재 상태 (코드로 확인함 — 너에게 묻지 않는다)

| 묻지 않을 것 | 이미 아는 답 |
|---|---|
| 칭찬은 어디에 저장되나 | 서버. 두 사람이 같이 본다. 보내면 상대에게 알림이 간다 |
| 「💝 칭찬 / 🥺 조르기 / 📝 메모」 | 칭찬 = 스티커 N장과 함께 칭찬 보내기, 조르기 = "나 칭찬해 줘" 부탁, 메모 = 짧은 포스트잇 |
| 왕관 👑 | 칭찬이 100번 쌓일 때마다 하나 |
| 아이폰 앱에서만 생기는 문제(키보드 등) | 이 브라우저로는 재현할 수 없다. 묻지 않는다 |

## 🚨 절대 금지 (꼼이에게 실제로 간다 — 되돌릴 수 없다)

- **보내기 0번.** 칭찬 쓰기 칸 아래 **보내기 버튼**(종이비행기·"보내기"·"졸라 보기"·"붙이기" 등 무엇이든)을 **누르지 마라.**
- 칭찬 줄을 눌러 열리는 **답글 창의 입력칸에는 글자를 치지 마라.** 거기선 Enter가 곧 전송이다. 답글 창은 **열어 보고 닫기만.**
- 답글·칭찬 **삭제** 금지.
- 홈 화면의 하트·범프·기분·선물·채팅 보내기 금지. 로그아웃 금지.

## ✅ 해도 되는 것 (꼼이에게 안 간다)

- 홈 → 칭찬 카드로 들어가기, 뒤로 나오기.
- 「💌 받은 칭찬 / ✏️ 내가 쓴 칭찬」 바꿔 보기, 위아래 스크롤, 「📜 옛 칭찬도 펼쳐보기」.
- 오른쪽 위 왕관(통계) 눌러 보기.
- **「✏️ 꼼이 칭찬하기」 펼치기·접기**, 그 안에서 칭찬/조르기/메모 바꿔 보기, 스티커 골라 보기, 개수(1·3·5·10·20) 눌러 보기.
- 쓰기 칸(큰 글 상자)에 **글자 쳐 보기는 괜찮다**(보내기만 안 누르면 아무 데도 안 간다). 다 보고 나면 **지우고 접어 둔다.**
- 칭찬 한 줄을 눌러 답글 창 **열어 보기만** 하고 닫기.

## 할 일

### A. 첫인상 (설명 없이)
1. 홈에서 칭찬으로 가는 길을 찾을 수 있나. 홈 칭찬 카드가 무엇을 알려 주나(숫자·"새" 표시 등).
2. 칭찬 화면을 처음 열었을 때 **3초 안에** 무슨 화면인지·무엇을 할 수 있는지 알겠나.
3. 받은 칭찬 한 줄을 읽어 보고: 누가·언제·왜·스티커 몇 장인지 **한눈에** 읽히나.

### B. 칭찬 보내기 흐름 (보내기 버튼 직전까지만)
4. 「꼼이 칭찬하기」를 찾고 펼쳐서, 칭찬 하나를 **보내기 직전까지** 만들어 본다(글자 → 스티커 → 개수). 어디서 멈칫했나, 순서가 자연스럽나.
5. 칭찬/조르기/메모 세 가지가 **무슨 차이인지** 설명 없이 알겠나. 바꿀 때 무엇이 달라지나.
6. 스티커 18장과 개수 고르기: 고른 게 표시되나, 스티커가 무슨 뜻인지 알겠나.
7. 다 쓰고 나서 **보내기 버튼이 어디 있는지** 바로 보이나(누르지는 마라). 휴대폰 폭에서 가려지거나 아래로 밀려 안 보이진 않나.

### C. 읽기·답하기
8. 받은 칭찬 / 내가 쓴 칭찬 바꾸기가 알아보기 쉬운가.
9. 칭찬 줄을 눌러 답글 창이 열린다는 걸 알 수 있었나(누르기 전에 힌트가 있나).
10. 왕관(통계)·왕칭찬 컬렉션: 무엇을 뜻하는지 알겠나.
11. 옛 칭찬 펼치기, 칭찬이 많을 때 스크롤이 지루하거나 길을 잃진 않나.

### D. 겉모습
12. 글씨(손글씨·본문)가 읽기 편한가, 작은 글씨·흐린 글씨가 있나.
13. 휴대폰 폭에서 넘치거나 겹치거나 잘리는 곳.
14. **이 화면에서 제일 마음에 드는 것 하나, 제일 답답한 것 하나.**
