## 무엇이 바뀌었나(검수 대상)
우댕이 "이모티콘 추천이 불편하다"며 카카오톡 흐름을 원했다. 그래서 이렇게 바꿨다:
1. 글을 칠 때 입력바 위에 뜨던 **큰 추천 줄은 이제 안 뜬다.**
2. 마지막 단어에 맞는 이모티콘이 있으면 **입력칸 오른쪽 스마일 단추가 그 이모티콘 작은 그림으로 바뀐다.**
3. 그걸 누르면 **이모티콘 서랍이 그 단어로 검색된 상태로 열린다.** 결과 위에 분홍 글씨 「고르면 입력한 「…」 대신 가요」.
4. 거기서 하나를 고르면 **입력칸에서 그 단어가 사라지고**, 고른 이모티콘이 **대화 위에 반투명 회색 카드**(왼쪽 위 ★, 오른쪽 위 ✕)로 뜬다. 보내기 단추를 누르면 간다(연습 모드라 실제로는 안 가고 토스트만).
5. 미리보기 ✕를 누르면 사라졌던 단어가 입력칸에 돌아온다.
6. 서랍에서 검색칸을 지우고 다른 탭에서 고르면 글은 그대로 남는다(이모티콘 + 글이 같이 가는 방식).

## 들어가는 법
1. Aside 브라우저에서 `https://kkommorning-v2.vercel.app/?practice=1` 을 연다. 새 코드가 늦게 올 수 있으니 **강력 새로고침**(캐시 비우고 새로고침)을 한 번 한다.
2. 꼼톡(채팅)을 연다. 노란 연습 모드 띠 확인. 없으면 멈춤.
3. 새 코드가 들어왔는지 확인: 입력칸에 「사랑해」를 쳤을 때 **입력바 위에 큰 그림 줄이 뜨면 옛날 코드**다 → 새로고침을 한 번 더 하고, 그래도 그러면 멈추고 보고.

## 해 볼 것 (하나마다 화면을 찍어 artifacts에 저장)
| # | 해 볼 것 | 볼 것 |
|---|---|---|
| T1 | 입력칸에 「사랑해」 | 오른쪽 스마일 단추가 작은 이모티콘 그림으로 바뀌는지 · 큰 추천 줄이 안 뜨는지 |
| T2 | 그 작은 그림을 누름 | 서랍이 열리고 검색칸에 「사랑해」, 결과 격자, 분홍 「고르면 입력한 「사랑해」 대신 가요」가 보이는지 · 키보드(있다면)가 내려가는지 |
| T3 | 결과 중 하나를 누름 | 입력칸이 비는지 · 미리보기 카드가 **서랍 위, 대화 위에 반투명**으로 뜨는지(뒤 대화가 비쳐 보이는지) · ★·✕ 위치 |
| T4 | 미리보기 ✕ | 카드가 사라지고 입력칸에 「사랑해」가 돌아오는지 · 서랍은 열린 채인지 |
| T5 | 다시 결과 하나 → 미리보기 ★ 누름 | ★가 노랗게 채워지고 「즐겨찾기에 담았어」 토스트 · 한 번 더 누르면 빠지는지 |
| T6 | 보내기 단추 | 연습 모드 토스트(안 보냈어요)가 뜨는지. 미리보기·입력칸 상태가 어떻게 되는지 적기 |
| T7 | 입력칸을 비우고 「오늘도 사랑해」 → 작은 그림 → 하나 고름 | 입력칸이 「오늘도」로 남는지 · 미리보기 아래 「입력한 글과 함께 가요」가 보이는지 |
| T8 | 입력칸을 비우고 「배고파」 → 작은 그림 → 서랍 검색칸 ✕로 지우고 아무 탭에서 하나 고름 | 입력칸 「배고파」가 **그대로** 남는지 |
| T9 | 입력칸을 비우고 「컴퓨터」 | 스마일 단추가 그대로 스마일인지(맞는 이모티콘이 없으니까) |
| T10 | 입력칸을 비우고 「행복」 → 작은 그림 → 검색 결과에서 **작은 말티푸 얼굴(미니)** 이 있으면 그걸 누름 | 입력칸이 「(행복)」으로 바뀌는지(없으면 「미니 없음」이라고 적기) |
| T11 | 서랍이 열린 상태에서 대화 부분을 한 번 누름 | 서랍이 닫히는지, 미리보기가 있었다면 남는지 |

끝나면 입력칸을 비워 두고, 꼼톡을 닫는다.
