## 우댕이 새로 말한 것(원문)
> 주간 달력 같은 것 또는 월간 달력에 스티커 같은 거 붙이는 기능도 있어? 생일 같은 것은 스티커 붙이고 전용으로.
> gpt랑 논의해봐. **다꾸하는 사람들은 달력 꾸미는 것도 좋아하잖아.**

→ 지난 회의의 「월 화면은 최소로」를 **다시 본다.** 종이 다이어리 꾸미는 사람들이 월간(먼슬리)·주간(위클리)에서 실제로 하는 일(날짜 칸 스티커, 마스킹테이프로 여러 날 잇기, 기념일 도장, 한 줄 메모, 날씨·기분 아이콘 등)을 떠올려서 답해 줘.

## 부탁
1. **결론 4줄.**
2. **월간 꾸미기 달력** — 폰 390px 에서 7열 칸(약 50px)에 무엇을 어떻게 올릴까: 칸마다 스티커 몇 개, 크기·자리(자유 끌기 vs 칸에 딱 붙기), 여러 날을 잇는 테이프(여행·시험 기간), 달 전체 장식(머리 그림·달 제목 손글씨·여백 스티커), 칸 한 줄 메모. 붙이는 손짓(서랍에서 고르고 날짜 톡? 끌어다 놓기?). 하루 장과의 관계(칸을 누르면 하루 장으로 / 하루 장에 붙인 대표 스티커가 칸에 비치기?).
3. **주간(위클리)** — 폰에서 할 가치가 있나. 한다면 어떤 모양(세로 7줄? 가로 넘김?), 하루 장·월간과 겹치지 않는 쓸모가 뭔가. 안 한다면 이유.
4. **생일·기념일 전용 스티커** — 등록할 때 고르는 전용 스티커가 매년 그 칸에 자동으로 붙는 방식, D-day·몇 주년 표시, 다가올 때 미리 보이기(「꼼이 생일 D-7」 같은 것 — 장부·재촉이 안 되게), 새로 그려야 할 그림 목록(우리 캐릭터: 꿀벌 옷 아기돼지 「꿀됑」·하얀 말티푸 「꼼이」) 8개 안쪽.
5. **둘이 쓰는 달력** — 월간은 둘이 같이 꾸미는 한 장인가, 각자인가(하루 장은 각자). 동시에 고칠 때 충돌, 누가 붙였는지 표시할지.
6. **데이터·성능** — 월간 장식 저장 모양(지금 하루 장은 `diaryPages/{date_owner}` + content), 한 달에 물건 몇 개까지, 달 넘길 때 버벅이지 않게. 우댕 제1 조건 「버벅이게 하는 것은 절대 금지」.
7. **1차에 넣을 것 / 미룰 것** + **Gemini 시안 의뢰에 추가할 컴포넌트·props**(지금 DiaryMonthSheet 를 어떻게 바꿀지).
8. **우댕이 정해야 할 것**(선택지 + 추천).
