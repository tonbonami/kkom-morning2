안녕, 또 Claude야. 이번엔 기능 설계 회의야. 파일은 열지 말고 이 글만 보고 답해 줘. 코드는 짧은 핵심만, 설명 위주로.

## 무엇을 만드나
- 커플 둘만 쓰는 iOS 앱 「꼼모닝」(TestFlight로 둘만 설치, App Store 공개 아님)에 **잠잘 때 듣는 백색소음(빗소리 등) 재생 기능**.
- 왜: 여자친구(꼼이)가 매일 밤 유튜브 빗소리를 틀어 놓고 자는데, 무료 유튜브라 **화면이 꺼지면 멈추고, 영상이 7시간짜리라 중간에 끝나고, 광고가 뜬다.** 남자친구(우댕)가 「백그라운드 재생 기능을 넣어 줄 수 있어? 위젯에 하는 게 나아? 좋은 방법 있어?」라고 물었어.
- 바라는 것: 광고 없이, 화면 잠가도, **아침까지(8~9시간) 끊기지 않고**, 자기 전에 **한 번에 쉽게** 켜는 것. 아침 알람은 반드시 울려야 함.

## 앱 구조(지금)
- Capacitor iOS 앱: 네이티브 껍데기(WKWebView)가 Vercel에 올린 Next.js 웹을 실시간으로 불러와 그린다. 화면 대부분이 웹.
- 네이티브 Swift 코드도 있다: 커스텀 Capacitor 플러그인 여러 개(햅틱, 푸시, 공동 낙서 캔버스 화면, Live Activity), **위젯 확장(KkomWidget)**에 iOS 17 인터랙티브 버튼(AppIntent, openAppWhenRun=false — 앱 안 열고 하트·범프를 서버로 보냄), 애플워치 앱, 알림 서비스 확장. 앱 그룹 공유 저장소 있음.
- 앱 최소 iOS 16. 둘 다 최신 아이폰(iOS 26대).
- Info.plist에 UIBackgroundModes는 **아직 없음**. 오디오 코드(AVAudioSession 등) 없음.
- 네이티브를 바꾸면 TestFlight 새 빌드가 필요(스크립트 한 방이라 부담은 적음). 웹은 바로 배포.

## 부탁
1. **재생 방식**: 웹(WKWebView의 `<audio>`/Web Audio)으로 하면 잠금·백그라운드에서 어떻게 되는지, 네이티브(AVAudioPlayer/AVAudioEngine + Capacitor 플러그인)로 해야 하는 이유. 네가 권하는 구조(누가 소리를 내고, 웹은 무엇만 하는지).
2. **켜는 곳**: 앱 안 화면 / **홈 화면·잠금화면 위젯 버튼** / iOS 18 **제어 센터 컨트롤** / Siri·단축어 / 애플워치 — 각각 되는지, 앱을 안 열고도 소리가 나는지(AudioPlaybackIntent 같은 것), 자기 전 「한 번에 쉽게」에 무엇이 제일 좋은지. 「위젯이 낫냐」에 대한 솔직한 답.
3. **소리 자체**: 빗소리 녹음 파일을 쓸지(저작권 걱정 없는 출처, 반복 이음새 없애는 법, 길이·용량) vs 코드로 만드는 백색·분홍·갈색 소음. 처음에 몇 가지 소리를 넣으면 좋을지.
4. **밤새 안정성**: 8~9시간 연속 재생에서 끊기는 원인(전화·다른 앱 소리·Siri·이어폰 빠짐·메모리·배터리)과 대처, 배터리 소모 대략, **아침 알람과 겹칠 때**(시계 앱 알람은 울리는지), 잠금화면 「지금 재생 중」 조작, 볼륨.
5. **타이머·마무리**: 끝까지 / N시간 / 아침 몇 시에 서서히 꺼지기 / 처음 몇 초 서서히 켜기 같은 것 중 무엇이 필요한지.
6. **커플 앱다운 한 가지**(선택): 둘만 쓰는 앱이라 넣을 만한 작은 아이디어가 있으면 1~2개만(예: 꼼이가 켜면 우댕 쪽에 「꼼이 잠들어요」 표시). 사생활·방해가 되지 않게.
7. **함정**: TestFlight 심사·백그라운드 오디오 모드 관련, Capacitor에서 흔히 틀리는 것.
8. **순서**: 처음 빌드 하나에 넣을 최소 기능과, 그다음에 붙일 것.

한국어로, 짧고 분명하게, 항목 번호대로 답해 줘. 모르거나 버전마다 다른 건 「확인 필요」라고 적어 줘.
