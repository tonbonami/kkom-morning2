> Teo에게: 1·2부와 **같은 Aside 대화에 이어서** 넣는다.
> 부작용은 1부와 같다(채팅을 열면 꼼이 메시지 읽음·우댕 접속 표시). 단 **"둘 다 접속하면 대화창 자동 열림"은 없앴다** — 꼼이 화면에 채팅이 저절로 뜨는 일은 이제 없다.

## 2부 고마워. 이렇게 고쳤다

네 2부 판정대로 고쳐서 배포했다(웹). 처방이 바뀐 곳:
- B1 서랍 손잡이 **뺐다**, ☺가 열리면 ⌨로 바뀌게 했다(네 의견 그대로).
- B3 하단 여백은 **이미 충분했다**(바 약 92px, 홈 아래 여백 110px). 네가 본 건 첫 화면에서 꼼톡 카드가 바 뒤에 걸친 모습이라, 카드 순서를 바꿀지는 Teo가 정한다. **이번엔 안 바뀌었다.**
- B4 툴팁은 PC용으로만 넣었다(시트 겹침·닫기 버튼이 본 처방).
- B8 칩 글자는 그대로 두고, 글 없이 누르면 한 줄 안내가 뜬다.
- A(키보드)는 아직 안 고쳤다. 네 말대로 **먼저 잰다.** Teo의 아이폰은 **iOS 27.0.1**, 앱은 빌드 54다.

## 너의 역할

1부와 같다. **이 앱을 오늘 처음 받은 사람**이자, 고친 게 정말 고쳐졌는지 보는 검수자.

## 현재 상태 (묻지 않는다)

| 묻지 않을 것 | 이미 아는 답 |
|---|---|
| 이모티콘 그림을 누르면 왜 바로 가나 | 일부러. 카톡처럼 한 번에 보낸다 |
| 컴퓨터에서 Enter | 곧바로 보내기 |
| 홈 꼼톡 카드 위치 | 이번엔 안 바꿨다(Teo 결정 대기) |
| 아이폰 키보드 가림 | 이 브라우저로는 재현 불가. 실기기로 따로 잰다 |

## 🚨 절대 금지 (1부와 같다)

- **보내기 0번**(메시지·사진·이모티콘·하트·선물·음성·타임캡슐). 이모티콘 그림·추천 이모티콘·보내기 버튼 누르지 마라.
- **채팅 입력칸에 글자를 치지 마라.** 클릭만.
- 메시지 메뉴의 **삭제·수정·보관** 누르지 마라.
- "이 사진을 보낼까요?"가 뜨면 반드시 '취소'. 로그아웃·홈의 하트·범프·기분·선물 금지.

## ✅ 해도 되는 것

- 스크롤, ＋·☺ 열고 닫기, **⌨ 버튼 누르기**, 입력칸 클릭
- 말풍선 눌러 메뉴 열기 → **Esc·바깥 클릭·'닫기'로 닫기**, '복사'
- 테마 시트·추억함 열고 닫기, 테마 골라 보기(이 브라우저에만 저장)
- **타임캡슐 칩을 글 없이 누르기**(안내만 뜨고 아무것도 안 간다)
- 링크 카드 누르기(새 탭), "이전 대화 더보기"
- 넓은 화면에서 채팅 양옆 어두운 곳 누르기(채팅이 닫힌다 — 다시 열면 된다)

창 크기는 1부와 같이 **390px 폭(iframe 흉내)** 과 **1440×900** 두 가지. 실제 창 폭을 적어라.

## A. 고친 것 확인

항목마다 `고쳐짐 / 반만 / 안 고쳐짐 / 못 봄`으로 판정하고, 1부와 같은 4줄(화면·한 일·본 것·진단) + 스크린샷.

| # | 1부에서 본 것 | 지금 기대하는 것 | 확인 방법 |
|---|---|---|---|
| A1 | ☺를 열면 메시지 영역이 703→336px, 마지막 말풍선(9:10)이 서랍 아래로 가려짐 | 영역은 줄어도 **마지막 말풍선이 보인다** | 390px에서 맨 아래까지 내린 뒤 ☺ 열기. ＋도 같이 |
| A2 | 서랍 연 채로 입력칸을 눌러도 서랍이 그대로 | 입력칸을 누르면 **서랍이 닫힌다**. 서랍이 열리면 ☺가 **⌨**로 바뀌고, ⌨를 누르면 닫힌다 | 390px |
| A3 | ＋를 열어도 모양 그대로 | 열리면 **×로 돈다** | 두 폭 |
| A4 | 메뉴가 글자 없는 아이콘 7개, Esc로 안 닫힘 | 위 줄 반응, 아래 줄 **답장·보관·복사·수정·삭제·닫기** 글자. Esc·바깥 클릭으로 닫힘 | **390px에서 메뉴가 한 화면에 들어오나** 꼭 볼 것(2부에서 못 봤다고 한 것). 맨 아래 말풍선을 눌러 메뉴가 화면 안으로 보이나 |
| A5 | 테마 시트 위에 추억함이 겹쳐 열림, 테마 시트에 닫기 버튼 없음 | 겹치지 않음, 테마 시트 오른쪽 위에 **×** | 두 폭 |
| A6 | 1440px에서 입력줄이 화면 끝까지 | 채팅이 **가운데 약 640px**, 양옆이 어둡다 | 1440 |
| A7 | 네이버 지도 카드에 주소 글자만 | **"에이직 피자"** 같은 가게 이름·사진, 출처 "네이버 플레이스" | "이전 대화 더보기"로 그 카드를 찾아서 |
| A8 | 타임캡슐 설명 없음 | 글 없이 누르면 **한 줄 안내**, 390px 폭을 안 넘침 | 390px |
| A9 | 헤더 아이콘 이름·툴팁 없음 | 1440에서 마우스를 올리면 **"챗 테마"·"추억 보관함"·"채팅 닫기"** | 1440. 홈 말풍선 아이콘은 **"꼼톡"** |
| A10 | 서랍 스티커 읽는 이름이 영어(happy…) | **행복·사랑·보고싶음…** | 접근성 이름 |
| A11 | (1부 못 봄) 인스타그램 링크 카드 | 썸네일·캡션 첫 줄·`Instagram · @아이디` | 대화에 인스타 링크가 있으면. 없으면 "못 찾음" |

## B. 고치면서 새로 생긴 문제 찾기

고친 자리 주변에서 **전에는 없던 불편**이 생겼는지 본다. 예를 들어:
- 메시지 메뉴가 넓어져서 **시간 표시나 옆 말풍선을 가리는지**
- ☺·＋를 열고 닫을 때 **목록이 덜컥 튀는지**
- 넓은 화면에서 **양옆을 눌러 채팅이 닫히는 게** 실수로 일어나기 쉬운지
- 그 밖에 이상한 것

없으면 "못 찾음".

## C. 조사 — iOS 27 키보드

Teo의 폰이 **iOS 27.0.1**이라 2부의 iOS 26 자료가 그대로 맞는지 모른다. 웹에서 찾아 줘(직접 열어 본 건 "확인", 못 열어 본 건 "미확인"):
1. iOS 27.0.x에서 **WKWebView·사파리 키보드가 입력칸을 가리는** 알려진 문제가 있나.
2. 2부에서 말한 iOS 26.0의 `visualViewport.offsetTop` 버그가 **27에서 고쳐졌나, 다시 생겼나.**
3. iOS 27에서 `<meta name="viewport" content="…, interactive-widget=resizes-content">`가 **먹히나.**
4. Capacitor 6 앱이 iOS 27에서 키보드 때문에 겪은 사례(이슈 주소).

## 기록 규칙 (1부와 같다)

- 본 것만 적어라. 못 본 것은 "못 봄". 추측하지 말 것. 화면 문구는 그대로.
- "○○가 없다" 대신 "○○를 못 찾았다".
- 판단이 안 서면 멈추고 "여기서 멈췄다".

## 보고 형식

A는 항목마다 `판정` + 4줄 + 스크린샷. B는 찾은 것마다 4줄. C는 질문마다 `답 / 근거 주소(확인·미확인)`.
