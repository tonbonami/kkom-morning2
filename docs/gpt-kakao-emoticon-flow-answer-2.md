1. 판단: **좋음.** 가장 예측 가능하고 덜 헷갈리는 규칙이야.

- 입력 전체가 이모티콘 뜻과 사실상 같을 때만 글을 지움.
- 문장에 다른 의미가 하나라도 섞이면 아무것도 지우지 않고 글 + 이모티콘으로 보냄.
- 카톡의 정확한 내부 판정 규칙은 **불확실**하지만, 우댕이 묘사한 기대에는 이 방식이 잘 맞아.

2. 꾸밈 목록

**포함:** 앞뒤 공백, `~ ! ? . … ♥ ♡`, 일반 이모지, `ㅋㅋ/ㅎㅎ/ㅠㅠ/ㅜㅜ`, 같은 글자 늘이기, 존댓말 `요`.

**추가:** 반복 문장부호(`!!!`, `~~`), 감탄형 꼬리(`사랑해앵`, `보고싶당`)는 확신할 수 있을 때만.

**빼거나 보수적으로:** `ㅋ/ㅎ` 한 글자, 임의의 받침·말투 변형은 오인식 가능성이 커서 자동 삭제하지 않는 편이 안전해.

핵심은 꾸밈을 제거한 뒤 **남는 의미 있는 글이 정확히 검색어 하나인지**야.

3. 경계 사례

- `꼼슌아 사랑해` → **글 유지 + 이모티콘**
- `사랑해 꼼슌아` → **글 유지 + 이모티콘**
- `사랑해 사랑해` → **글 유지 + 이모티콘** — 반복도 표현의 일부
- `ㅋㅋㅋ` → 해당 이모티콘이 `ㅋㅋㅋ` 의미라면 **글 삭제**
- `응` → `응` 이모티콘이면 **글 삭제**
- `배고파 ㅠㅠ` → `ㅠㅠ`는 꾸밈이므로 `배고파` 이모티콘이면 **글 삭제**
- `잘자 꿈꿔` → **글 유지 + 이모티콘**

4. 더 똑똑하게 만들 것

- 서랍에서 고르는 순간이 아니라 **미리보기에서 무엇이 전송될지 그대로 보여주기**. 자동 규칙보다 확실해.
- 문장인지 애매하면 무조건 **글 유지**. 잘못 남기는 것은 조금 중복될 뿐이지만, 잘못 지우면 뜻이 사라져.

작은 글은 `입력한 글과 함께 가요`보다 **`글은 그대로 두고 함께 보내요`**가 더 명확해. 삭제 때도 침묵보다 **`‘사랑해’ 대신 보내요`**를 보여주는 편이 예측 가능해.
