# GPT 상의 — 꼼모닝 「편지」 기능 새 단장 (2026-11-06)

너는 이 저장소(꼼모닝, Next.js 15 + Tailwind + Firestore, iOS 앱은 Capacitor 웹뷰)를 **읽기만** 하는 상의 상대다.
**파일을 만들거나 고치지 마라.** `.env*`·`*.p8`·`*.pem`·`*.key`·`GoogleService-Info.plist`·`*secret*`·`certs/` 는 열지 마라. `node_modules/`·`.next/` 는 건너뛰어라.
답은 **한국어**로, 근거는 `파일:줄` 로.

## 배경
- 2인용 커플 앱이다(우댕 ↔ 꼼이). 「편지」는 오래된 기능이라 처음 만든 모양 그대로다.
- 우댕 요청(원문): 「편지기능 좀 업뎃해볼까? 너무 오래 예전 폼팩터 그대로네. 문장 중간중간에 미니 이모티콘 쓸 수 있으면 좋겠다.」
- 우리 팀 방식: 화면 디자인 시안은 Gemini, 그림(편지지·스티커 등 자산)은 ChatGPT, 코드 통합은 Claude. 이번엔 **방향과 설계**만 정한다.

## 묻는 것
1. **「예전 폼팩터」를 요즘 커플 앱 편지답게 바꾸려면** 무엇을 바꾸는 게 효과가 큰가? 쓰기·읽기·목록·홈 카드 각각. 실제 앱(카카오톡 선물 메시지 카드, 라인, Between, 썸원, 손편지 앱 등)에서 검증된 패턴 위주로. 과한 꾸밈 말고 **매일 쓰고 싶어지는** 쪽.
2. **문장 중간 미니 이모티콘** — 쓰는 화면을 어떻게 만들까?
   - textarea + 토큰 글자(꼼톡과 같은 `(단어)`) + 아래 미리보기 vs `contenteditable` 로 그림이 글 속에 바로 보이게 — iOS 웹뷰(한글 조합 IME, 커서, 붙여넣기, 키보드) 기준 위험과 추천.
   - 넣는 길: 커서 자리에 넣기, 꼼톡 서랍 재사용, 단어 치면 추천(꼼톡 흐름) 중 무엇을.
   - 읽는 화면·홈 카드·알림·예약편지 봉인·옛 편지와의 호환.
3. **편지지/봉투/열어 보기 같은 연출**을 넣는다면 어디까지가 적당한가(MVP / 다음 / 하지 말 것). 손글씨 글꼴, 편지지 고르기, 봉투 여는 애니, 날짜 도장 등.
4. **단계별 계획** — MVP(1~2일)·2차·3차로 나누고, 각 단계에서 바꿀 파일과 데이터 필드(추가하면 옛 편지가 어떻게 보이는지)까지.
5. **위험·함정** — 이 저장소에서 실제로 걸릴 만한 것(예약편지 봉인 경로, 알림 미리보기, 댓글, 본문 수정 기능, 손글씨·영상 크기 등).
