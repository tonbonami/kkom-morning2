> 꼼모닝 세션(Claude Code)이 Aside CLI로 직접 보낸다. Teo 요청: "꼼이 피부 일지 Aside 검수 받자."
> - **이번 의뢰만 한다.** 이 대화에 남아 있는 예전 지시(꼼톡 검수·Kling 등)는 하지 않는다.
> - 로그인은 Aside 브라우저에 이미 된 상태(우댕)를 쓴다. 로그아웃돼 있으면 **멈추고 보고**(로그인 코드를 추측·입력하지 마라).
> - **PIN 입력 화면이 나오면 즉시 멈추고 보고**한다. PIN을 추측하거나 숫자를 눌러 보지 마라(5번 틀리면 꼼이가 15분 잠긴다).
> - 이 의뢰서는 파일을 열 필요 없이 이 글 전체가 지시다.

## 무엇을 보나

꼼이(우댕의 여자친구)가 5월부터 원인 모를 두드러기·가려움을 겪고 있어서, 꼼모닝 앱에 **「꼼이 피부 일지」**를 만들었다. 매일 점수·약·의심 요인을 적고, 사진을 남기고, 분석 화면에서 패턴을 보고, Claude와 상담한다. 이번엔 **꼼이가 매일 30초 안에 적을 수 있는지, 칸 이름이 알아들을 만한지, 분석·상담 화면이 믿음직한지**를 본다.

## 🧪 「연습 모드」로 한다 — 실제 기록은 하나도 안 보인다

주소: **https://kkommorning-v2.vercel.app/?practice=1**

연습 모드에서 피부 일지는 **지어낸 예시 기록 24일치**로 열리고, PIN을 묻지 않는다. 저장·사진·설정은 이 탭에만 남고(새로고침하면 처음으로), 서버로 아무것도 안 간다. 상담은 실제 Claude 대신 정해진 안내 문장이 흘러나온다.

**맨 먼저 확인:** 홈에서 「피부 일지」 카드(청진기 아이콘, 오른쪽에 의사 꿀됑 선 그림)를 누르면 기록 화면 아래쪽에 노란 띠 **「🧪 연습 모드 — 예시 기록이에요 · 저장·사진·상담이 실제로 안 나가요」**가 보여야 한다.
→ **띠가 안 보이면 즉시 멈춰라.** 아무것도 누르지 말고 스크린샷과 함께 "띠 없음"으로 보고한다.
→ PIN 숫자판이 보여도 즉시 멈추고 보고한다.

### 🚨 절대 금지 (연습 모드가 막지 않는 곳)
- **홈 화면**의 하트·범프·기분·선물·아래 퀵메시지 바 — 누르면 꼼이 폰에 진짜로 간다.
- 꼼톡·편지·칭찬·달력 등 **피부 일지 밖 화면**에서 무언가 쓰거나 보내기.
- 로그아웃. 주소에서 `?practice=1`을 빼고 들어가기(바뀌었으면 위 주소로 다시 들어와 띠부터 확인).
- 사진 올리기에서 **실제 파일을 고르지 마라** — 파일 고르기 창이 뜨는지만 보고 취소.

### ✅ 해도 되는 것 (띠가 보일 때, 피부 일지 안)
- 기록 화면의 모든 칸 누르기·쓰기·펼치기·저장, 7일 띠에서 날 바꾸기, 「힘든 날 우댕에게 알리기」 스위치.
- 분석 화면(오른쪽 위 「분석」), 상담 화면(분석 맨 아래 「Claude와 상담하기」)에서 예시 질문 칩·입력칸.
- 다 보고 나면 그냥 두면 된다(새로고침하면 예시로 돌아감).

## 현재 상태 (코드로 확인함 — 너에게 묻지 않는다)

| 묻지 않을 것 | 이미 아는 답 |
|---|---|
| 보이는 숫자·메모 | 전부 지어낸 예시. 꼼이 실제 기록 아님 |
| 실제(연습 아님) 모드에서 우댕 폰 | 보기 전용 — 칸은 펼쳐 볼 수 있고 값 바꾸기·저장·사진·상담 보내기는 막힘. 쓰기는 꼼이만 |
| 연습 모드에서 보기 전용 흉내 | 주소 `?practice=1&view=1` (끄기 `&view=0`) |
| 상담 답 | 연습 모드에선 정해진 안내 문장. 실제로는 Claude Opus 5.5가 기록 30일치를 보고 답함 |
| 아이폰 상태바 자리 덮개 | 브라우저로는 재현 안 됨. 보지 않아도 된다 |
| 디자인 | 제미나이 시안을 그대로 넣었다. 「예쁘다/아니다」보다 **쓰기 불편한 곳·헷갈리는 말**을 찾아 줘 |
| 초진 설문 화면 | 아직 없음(디자인 받는 중). 보지 않는다 |

**창 크기 두 가지로 각각 본다:** ① 휴대폰 폭(목표 390px, 모바일 흉내 기능이 있으면 그걸로), ② 평소 컴퓨터 크기. 보고에 **실제 창 폭(px)**을 적어라. 가능하면 다크 모드도 한 번.

## 할 일

### A. 30초 기록 (가장 중요)
오늘 날짜에서 「팽진 보통 + 가려움 약간 + 항히스타민 먹음 + 저장」까지 **몇 번 눌렀고 몇 초** 걸렸는지. 「오늘은 증상 없음」으로 끝내는 경우도 한 번.

### B. 칸 이름만 보고 알겠나
11칸(오늘 점수 · 약 · 두드러기 올라온 시각·부위 · 붓기 · 흔적 · 의심 가는 것 · 먹은 것 · 생활 · 생리 · 새로 쓴 제품 · 메모)마다: 제목만 보고 뭘 적는 칸인지 바로 알겠는지(○/△/✕와 한 줄 이유), 펼쳐서 적기 불편한 점, 접었을 때 요약 줄이 맞는지.

### C. 7일 띠
날 바꾸기가 잘 되는지, 동그라미 색 진하기(점수)와 아래 ✓ ✕ 시계(약)가 무슨 뜻인지 설명 없이 읽히는지. 저장 안 한 채 날을 바꾸면 어떻게 되는지.

### D. 사진 칸
빈 상태 안내 문구가 잘리는지, 「+ 추가」·카메라 칸을 누르면 파일 고르기 창이 뜨는지(뜨면 바로 취소).

### E. 「힘든 날 우댕에게 알리기」
설명을 읽고 언제 무엇이 가는지 이해되는지. 켜고 끄기가 되는지.

### F. 분석 화면
- 의사 꿀됑이 위 띠에서 **좌우로 걸어 왕복**하는지(끝에서 뒤돌아서는지, 순간이동·잘림·떨림 없는지).
- 「최근 7일 UAS7」 숫자·색 막대, 30일 그래프(약 거른 날 빨간 막대), 「약 거른 다음날 vs 먹은 다음날」, 「주요 의심 요인」 표(「생리 중」「생리 전 1주」 줄 포함)가 **설명 없이 이해되는지**. 「UAS7」이라는 말을 처음 보는 사람이 알 수 있는지.
- 「전문적이되 무섭지 않은」 느낌인지 `[의견]`.

### G. 상담 화면
상대가 **사람이 아니라 Anthropic의 Claude**라는 게 바로 보이는지, 「진단이 아니에요 · 119」 띠가 읽히는지, 예시 칩을 누르면 답이 글자씩 흘러나오는지, 입력칸·보내기.

### H. 보기 전용 흉내
`?practice=1&view=1`로 다시 들어가(홈 → 피부 일지) 칸이 **펼쳐지는지**, 값을 눌러도 안 바뀌고 안내가 뜨는지, 「보기 전용이에요」 줄이 보이는지. 끝나면 `?practice=1&view=0`.

### I. 깨짐·잘림·버그
390px에서 가로로 밀리는 곳, 글자 잘림, 겹침(노란 띠와 저장 막대 포함), 콘솔 오류.
