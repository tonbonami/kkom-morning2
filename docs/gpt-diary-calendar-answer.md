## 1. 결론 4줄

1. 월간은 단순 날짜 선택창이 아니라, 둘이 함께 꾸미는 핵심 다꾸 장으로 승격하는 게 맞아요.
2. 50px 날짜 칸에서는 자유 배치보다 `고정 자리 스티커 2개 + 한 줄 메모`가 예쁘고 안정적입니다.
3. 위클리는 폰에서도 가치가 있지만, 월간·하루 장을 먼저 완성한 뒤 2차로 넣는 게 좋아요.
4. 1차 핵심은 `공동 월간 한 장 + 기념일 자동 스티커 + 기간 테이프 + 하루 장 연결`입니다.

## 2. 월간 꾸미기 달력

현재 월 선택창은 42칸, 최소 높이 44px이고 날짜를 누르면 바로 닫힙니다. `DiaryMonthSheet.tsx:79-143`

추천 구조:

- 날짜 칸 높이 62~68px, 폭 약 48~50px
- 위: 날짜 숫자
- 가운데: 16~18px 스티커 최대 2개
- 아래: 9~10px 한 줄 메모, 최대 6~7자
- 스티커는 자유 끌기 대신 `왼쪽·오른쪽 자리`에 딱 붙이기
- 칸을 가리는 큰 스티커와 회전은 금지

붙이는 방법은 `꾸미기 → 서랍에서 스티커 선택 → 날짜 톡`을 추천해요. 작은 칸으로 직접 끌기는 손가락에 가려집니다. 기본 보기에서는 날짜 톡으로 하루 장을 열고, 꾸미기 모드에서만 날짜 톡으로 붙입니다.

기간 테이프는 `테이프 선택 → 시작일 → 종료일` 순서로 붙입니다. 주 경계에서 자동으로 여러 조각으로 나누고 여행·시험·휴가 같은 짧은 이름을 넣습니다. 최대 8개 기간으로 제한합니다.

달 전체 장식은 격자 위가 아니라 다음 영역만 허용합니다.

- 상단 머리 그림 1개
- 달 제목 손글씨 프리셋
- 좌우·아래 여백 스티커 최대 6개
- 배경 종이·테이프 테마

하루 장과는:

- 날짜 칸 톡 → 그 사람의 하루 장
- 월간은 공동, 하루 장은 기존처럼 우댕·꼼이 전환
- 1차에는 하루 장의 스티커를 자동 복제하지 않고 작성 점만 표시
- 2차에 하루 장 물건 하나를 `월간 대표로 보이기`로 선택

현재 월간은 내 장·상대 장 작성 점만 표시합니다. `DiaryMonthSheet.tsx:135-139` 하루 장은 이미 소유자 전환 구조입니다. `DiaryDayScreen.tsx:187-216`

## 3. 위클리

폰에서도 가치는 있어요. 월간보다 자세하고 하루 장보다 빨리 한 주를 정리하는 자리입니다.

모양은 `세로 7줄 + 좌우로 주 넘김`이 가장 좋아요.

- 하루마다 날짜, 대표 스티커 1개, 1~2줄 메모
- 주간 목표·할 일보다 “이번 주 기억” 중심
- 기간 테이프와 주간 대표 사진 1장
- 각 줄 톡 → 해당 하루 장

다만 1차에서는 미룹니다. 월간·위클리·하루 장을 동시에 만들면 같은 메모와 스티커를 어디에 붙여야 하는지 헷갈립니다. 월간 사용량을 본 뒤 `주간 회고가 실제로 필요한지` 확인하고 넣는 편이 안전합니다.

## 4. 생일·기념일 전용 스티커

기념일 등록 폼에 `전용 스티커 선택`을 추가합니다. 지금 타입과 등록 폼에는 스티커 ID가 없습니다. `diaryTypes.ts:27`, `DiarySpecialDatesSheet.tsx:46-56`

- 매년 해당 날짜에 자동 표시
- 월간 장식 개수에는 포함하지 않음
- 시작 연도가 있으면 `우리 3주년`
- 당일 전에는 월간 상단에 `곧 꼼이 생일 · 7일` 한 개만 표시
- 푸시 재촉, 지나간 날짜 경고, 준비 체크리스트는 없음
- 현재 시험 화면은 날짜당 기념일 하나만 `find()`하므로 여러 개 배열로 바꿔야 합니다. `diary/test/page.tsx:113-124`

새 그림은 8개면 충분합니다.

1. 생일 케이크를 든 꼼이  
2. 꿀 케이크를 든 꿀됑  
3. 둘이 하트 초를 끄는 기념일  
4. 선물상자에서 얼굴을 내민 둘  
5. 꽃다발을 건네는 꿀됑  
6. 여행가방 옆의 둘  
7. 왕관을 쓴 꼼이  
8. 작은 달력을 함께 든 둘  

## 5. 둘이 쓰는 달력

월간은 `둘이 같이 꾸미는 한 장`을 추천해요. 각자 월간을 따로 만들면 날짜 칸이 작아 꾸민 결과도 갈리고, 함께 쓰는 재미가 약해집니다.

- 누가 붙였는지는 평소 숨김
- 물건을 선택했을 때만 `우댕이 붙임` 표시
- 데이터에는 `createdBy`, `updatedAt` 저장
- 서로 다른 물건은 각각 저장
- 같은 물건을 동시에 고쳤을 때는 나중 저장을 적용하고 “꼼이가 방금 바꿨어요” 정도만 안내
- 삭제는 즉시 확정하지 않고 짧은 실행 취소 제공

하루 장은 기존대로 개인별입니다. 현재 타입도 하루 장에 `owner`를 둡니다. `diaryTypes.ts:23`

## 6. 데이터·성능

```text
diaryMonths/{YYYY-MM}
  themeId, titleStyle, revision, updatedAt

diaryMonths/{YYYY-MM}/content/main
  dayDecor: { 날짜: { stickers, memo } }
  spans: 기간테이프[]
  marginItems: 장식[]
```

각 물건에는 `id, assetId, slot, createdBy, updatedAt`을 둡니다. 배열 전체를 매번 덮지 말고 물건 ID 경로만 갱신하면 동시 편집 충돌이 줄어요.

안전선:

- 날짜당 스티커 2개
- 한 달 장식 총 60개
- 기간 테이프 8개
- 여백 장식 8개
- 정지 WebP만 사용
- 현재 달만 DOM에 표시
- 앞뒤 달은 숫자·기념일 데이터만 미리 읽기
- 달을 넘긴 뒤 이미지 지연 로딩
- 끌기 중 저장·React 상태 갱신 금지, 손을 뗄 때 한 번 저장

하루 장도 물건 30개 제한이며 `pointermove`에서는 transform만 바꾸고 끝날 때 콜백을 한 번 호출합니다. `diaryTypes.ts:30-31`, `DiaryPaper.tsx:61-110` 기존 저장안 역시 메타와 내용을 나눠 월 화면에서 무거운 내용을 읽지 않도록 했습니다. `docs/gpt-diary-answer.md:120-166`

## 7. 1차와 이후

1차:

- 공동 월간 꾸미기
- 날짜당 스티커 2개와 한 줄 메모
- 시작일·종료일 기간 테이프
- 상단 제목·머리 그림·여백 장식
- 기념일 전용 스티커와 주년 계산
- 날짜 톡으로 하루 장 이동
- 동시 편집용 물건별 저장과 실행 취소

미룰 것:

- 위클리
- 월간 완전 자유 배치
- 하루 장 대표 스티커 자동 반영
- 손글씨 직접 그리기
- 사진을 날짜 칸에 표시
- 편집 기록 화면

Gemini 의뢰에는 기존 `DiaryMonthSheet`를 전체 화면형 `DiaryMonthScreen`으로 확장하도록 요청하는 게 좋아요. 현재 props는 날짜 선택에만 맞춰져 있습니다. `DiaryMonthSheet.tsx:8-17`
