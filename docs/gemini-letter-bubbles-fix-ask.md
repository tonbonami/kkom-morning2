
## 생각풍선 자리 — 고칠 점 (실제 편지 읽기 창에 붙여 보니)

우댕이 폰 시험 화면에서 「끊긴 장면 0개, 1.3초, 풍선은 읽는 내내」로 정했다. 실제 읽기 창에 붙여 보니 자리가 두 군데 어긋난다. **`LetterCornerBubbles.tsx`·`EnvelopeReveal.tsx` 두 파일 완성본**만 다시 줘(props·성능 규칙 그대로, 다른 건 바꾸지 마).

### 읽기 창에서 편지지가 놓인 자리(숫자)
- 화면 폭 390px. 편지지 바깥으로 **왼쪽·오른쪽·위·아래 모두 24px** 의 빈 자리가 있고, 그 밖은 잘린다(스크롤 칸 경계, 오른쪽 끝은 화면 끝).
- 편지지 안: 왼쪽 위에 「To. 우댕」(왼쪽 24px·위 24px 에서 시작, 글자 높이 약 30px, Dongle 굵게). 오른쪽 위엔 내가 보낸 편지일 때 「수정」 단추(높이 44px). 오른쪽 아래엔 동봉한 큰 이모티콘(사인 붙음) 또는 「From. 이름 날짜」 도장(오른쪽 24px·아래 24px 안쪽).

### 고칠 것
1. **`LetterCornerBubbles` 왼쪽 위 꿀됑 풍선이 「To. 우댕」의 첫 글자를 덮는다.** 글자를 가리지 않게.
2. **오른쪽 아래 꼼이 풍선이 화면 오른쪽 끝에 잘린다.** 24px 빈 자리 안에서 잘리지 않게(꼬리 방울 포함).
   → 둘 다: 풍선을 편지지 모서리 **바깥쪽 빈 자리 + 모서리**에 걸치되 글자·단추·도장·이모티콘을 덮지 않는 크기·자리로. 필요하면 조금 작게(44~52px).
3. **`EnvelopeReveal` 닫힌 봉투에서 꼼이 풍선(오른쪽 아래)이 「From. 꼼이」 끝 글자를 아직 조금 가린다.** 이름이 다 보이게.

코드 블록 두 개만, 설명은 맨 끝 2줄.
