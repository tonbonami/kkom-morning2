## 배경

꼼톡(앱 안 채팅)에서 「사랑해」를 치면 입력칸 위에 추천 이모티콘 줄이 뜬다. 예전엔 추천 이모티콘을 누르면 **이모티콘만** 가고 「사랑해」 글이 입력칸에 그대로 남아서, 우댕이 매번 지우고 새로 썼다. 우댕이 카톡에서 확인해 보니 카톡은 이모티콘과 친 글이 **같이** 나간다.
→ 꼼모닝 세션이 고쳤다: 이모티콘(추천 줄·서랍 둘 다)을 고르면 **이모티콘 먼저, 이어서 친 글**이 나가고 입력칸이 비워진다. 글이 없으면 이모티콘만. 메시지 수정 중일 땐 글은 그대로. 「미니(단어)」 이모티콘은 지금처럼 글 안에 끼워 넣기.

## A. 카톡은 정확히 어떻게 하나 (웹 조사)

카카오 고객센터·공지·도움말(cs.kakao.com, kakaocorp 공지 등 **공식 출처 우선**)에서 확인해 줘:
1. 입력칸에 글을 쓴 채 이모티콘을 고르면 → **바로 전송**인가, **미리보기(입력칸 위에 이모티콘이 떠 있고 전송을 눌러야 감)**인가?
2. 전송하면 이모티콘과 글이 **한 말풍선(묶음)**으로 가나, **두 개**로 가나? 순서는?
3. 글 입력 중 뜨는 **「이모티콘 추천」(키워드 추천)**에서 고를 때도 같은가?
출처 링크를 꼭 붙이고, 공식 자료에서 못 찾으면 「못 찾음」이라고 적어라(추측 금지).

## B. 꼼톡 연습 모드에서 확인

주소: **https://kkommorning-v2.vercel.app/?practice=1** → 홈에서 꼼톡(채팅) 열기.
연습 모드에선 채팅을 보내도 **실제로 안 가고** 「🧪 연습 모드 — … 안 보냈어요」 알림이 뜬다(채팅 머리 아래 노란 띠). **띠가 안 보이면 즉시 멈추고 보고.**

### 🚨 절대 금지
- **홈 화면**의 하트·범프·기분·선물·아래 퀵메시지 바 — 연습 모드가 안 막는다(꼼이 폰에 진짜로 간다). 홈에선 꼼톡을 여는 것만.
- 편지·칭찬·달력·피부 일지 등 다른 화면에서 쓰기·보내기, 로그아웃, `?practice=1` 빼기.
- 사진·동영상·음성 올리기.

### 할 일
1. 입력칸에 「사랑해」 → 추천 줄이 뜨는지 → 추천 이모티콘 하나 누르기 → 알림이 **이모티콘**, 이어서 **「사랑해」** 순으로 뜨는지(빠르게 지나가면 둘 다 떴는지만), **입력칸이 비었는지**.
2. 입력칸에 「배고파」 → 이모티콘 서랍(입력칸 옆 이모티콘 버튼)에서 아무 이모티콘 → 1과 같은지.
3. 입력칸을 비운 채 서랍에서 이모티콘 → 이모티콘만(입력칸 그대로 빈 칸).
4. 「미니」(글 안에 들어가는 작은 단어 이모티콘) 탭이 있으면 하나 골라 → 전송되지 않고 입력칸 글 안에 들어가는지.
5. 연습 모드라 실제 말풍선 순서는 못 본다 — 볼 수 있는 것(알림 순서·입력칸)만 적어라.
