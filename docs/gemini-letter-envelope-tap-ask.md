
## 봉투 — 「누르면 열리게」 (우댕: 「열자마자 바로 열리네. 클릭하면 봉투 열리게」)

지금은 편지 창이 뜨면 닫힌 봉투가 잠깐 보였다가 저절로 열린다(phase 가 closed → 곧바로 opening). 이제 **닫힌 봉투에서 기다리다가, 꼼이가 봉투를 눌러야 열리게** 바꾼다. 여는 순서(1.3초)·겹침·밀랍·생각풍선 자리·성능 규칙은 지금 그대로.

`EnvelopeReveal.tsx` **완성본 하나만** 다시 줘:
- props 에 `onOpen?: () => void` 추가 — `phase === 'closed'` 일 때 **봉투 전체가 누르는 단추**(aria-label 「봉투 열기」, 누르는 영역 넉넉히). 누르면 `onOpen()` 만 부른다(phase 는 내가 opening 으로 바꾼다). `onOpen` 이 없으면 지금처럼 누를 수 없는 그림.
- 닫힌 봉투 아래(또는 위)에 짧은 안내 한 줄: 「봉투를 눌러 열어 봐」 정도(Dongle 또는 본문 글꼴, `palette.labelInk` 나 `--sd-muted`). 열리기 시작하면 사라짐.
- 누를 수 있다는 느낌: `whileTap` 으로 살짝 눌림 + (원하면) 닫힌 봉투가 처음 나타날 때 **한 번만** 살짝 흔들림/떠오름. **무한 반복 금지**(우댕 제1 조건 「버벅이게 하는 것은 절대 금지」 — transform·opacity 만).
- 「바로 열기」 단추: 닫힌 상태에선 봉투를 누르는 것과 겹치니 네가 판단해서 정리(예: 닫힌 상태엔 숨기고 여는 중에만 「건너뛰기」로).

코드 블록 하나만, 설명 2줄.
