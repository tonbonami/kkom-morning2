
## 편지지 2탄 — 다시: 「촌스럽다」는 평을 받았다

편지마다 편지지를 골라 보내는 기능을 만들고 있다. 첫 시안(아래 6장)을 우댕에게 보여 줬더니 **「편지지 넘 촌스럽다」**는 평을 받았다. 처음부터 다시, 네가 생각하는 **제일 세련된** 편지지로 만들어 줘.

### 촌스럽다는 평을 받은 6장 (이렇게 하지 말 것)
- 살구 단색 #F9E0D6 (이건 지금 기본 편지지이고 우댕이 고른 색 — 남긴다)
- 꿀단지: 진노랑 #FCE7A6 + 갈색 점 무늬 전면 반복
- 꼼이발자국: 진분홍 #FAD5DF + 분홍 발바닥 무늬 전면 반복
- 맑은하늘: 하늘색 #D4E7F7 + 파란 점 무늬 전면 반복
- 줄노트: 연두 #DCEEE2 + 초록 줄(글줄과 안 맞음)
- 체크: 살구 #F9DDD1 + 살구빛 깅엄 체크 전면 반복
→ 내 짐작: 채도 높은 파스텔을 종이 전체에 깔고, 그 위에 같은 무늬를 빽빽이 반복해서 아이 문구·포장지처럼 보였다.

### 방향
- 느낌: **잘 만든 문구점 편지지**(일본·유럽 고급 문구 브랜드의 레터 세트처럼). 절제, 여백, 종이 질감. 무늬가 있다면 아주 옅게 / 한쪽 가장자리·모서리에만 / 종이 결처럼 거의 안 보이게.
- 색: 탁하고 차분한 톤(톤 다운된 살구·장미·세이지·하늘·꿀빛 등)도 좋다. 단, **흰 말티푸 미니 이모티콘(흰 털, 글 속 28px 그림)이 묻히면 안 된다** — 그래서 흰색·아이보리처럼 너무 밝은 바탕은 안 되고, 기본 살구(#F9E0D6) 정도 밝기에 색감이 있어야 한다(우댕이 아이보리에서 「꼼이 이모티콘 잘 안 보여」, 베이지에서 「색감도 없네」라고 했다).
- 둘만 쓰는 커플 앱이다(꿀벌 조끼 아기돼지 「꿀됑」, 흰 말티푸 「꼼이」). 캐릭터 그림을 깔 필요는 없다 — 이름·색·작은 디테일로 은은하게 떠오르면 충분.
- 본문 글자는 진한 색 `#2E1D26`, 16px, 줄간격 1.8(=28.8px). 줄 무늬를 쓴다면 글줄과 맞게(28.8px 간격, 첫 줄 시작 위치는 내가 맞출 테니 간격만 정확히).

### 할 수 있는 것 / 없는 것
- 지금 구조: 편지지 바탕 = `div` 하나의 인라인 `style`(backgroundColor·backgroundImage·backgroundSize·backgroundPosition·backgroundRepeat 등 CSS 배경 속성 전부 가능, 여러 겹 그라디언트 가능, `box-shadow: inset` 도 가능). 그림 파일은 아직 없다.
- **CSS 만으로 세련되게 안 된다고 보면 솔직하게 말해 줘.** 그럴 땐 「종이 질감 그림(이음매 없이 반복되는 정사각 타일 PNG/WebP)」을 그림 생성 AI(ChatGPT)로 그려서 `backgroundImage: url(...)` 로 까는 길이 있다 — 그 경우 각 편지지마다 **그림 생성용 영어 프롬프트**도 같이 줘(무엇을, 어떤 질감·색·크기로, 이음매 없이 반복되게).

### 답 형식
1. 맨 위에 3~5줄: 이번 방향 한 줄 요약 + CSS 만으로 충분한지/그림이 나은지 네 판단.
2. `src/lib/letterPapers.ts` 완성본 — 인터페이스는 그대로(아래). **편지지 5~6장, 첫 장은 살구 `peach` 그대로**(`style: { backgroundColor: '#F9E0D6' }`, 글자·도장 색도 지금 그대로). 나머지 id 는 새로 지어도 된다(영어 소문자). 그림이 낫다고 판단한 편지지는 `style` 에 CSS 로 최대한 가까운 대체안을 넣고, 주석으로 그림 프롬프트를 달아.
```ts
import type React from 'react';
export interface LetterPaperTheme {
  id: string; name: string;          // name: 짧은 한국어(2~4글자)
  className: string;                 // '!bg-[#…] sd-card-paper' (바탕색만, 호환용)
  style: React.CSSProperties;        // 실제 바탕·무늬(인라인)
  ink: string; muted: string;        // 본문·흐린 글자색
  stamp: { bg: string; fg: string; border: string };   // From 날짜 도장(실제 CSS 색 값)
}
export const DEFAULT_PAPER_ID = 'peach';
export const LETTER_PAPERS: LetterPaperTheme[];
export function paperById(id?: string | null): LetterPaperTheme;   // 모르는 id → 살구
```
3. 날짜 도장(`From. 꼼이 2026. 11. 7`, Dongle 글꼴 작은 라벨)도 편지지마다 어울리게 색을 맞춰 — 지금은 전부 코랄 알약이라 편지지와 따로 논다.

코드 블록은 그 한 파일만. 파일을 열거나 명령을 실행하지 말고 답에 써 줘.
