## 보낼 글

커플 앱(둘만 쓰는 앱, 사용자 이름은 「우댕」과 「꼼이」)의 iOS 네이티브 **낙서장(둘이 같이 그리는 그림판)** 화면에 들어갈 SwiftUI 뷰를 만들어 줘. **iOS 16에서 돌아가야 해**(iOS 17 전용 API 금지, 외부 라이브러리 금지). 라이트 모드 전용.

### 지금 화면 분위기 (그대로 따라가기)
- 크림 배경 `Color(red: 1.0, green: 0.988, blue: 0.961)` 위에 흰 종이 보드, 둥근 모서리 16.
- 떠 있는 조작부는 전부 `.ultraThinMaterial` 캡슐 + 따뜻한 그림자 `Color(red: 0.47, green: 0.39, blue: 0.31).opacity(0.14)`, radius 8~10, y 4~6.
- 글씨색(먹) `Color(red: 0.20, green: 0.25, blue: 0.33)`.
- 둘의 색: **꼼이 = 로즈** `Color(red: 0.98, green: 0.48, blue: 0.66)`, **우댕 = 하늘** `Color(red: 0.49, green: 0.83, blue: 0.99)`.
- 아이콘은 SF Symbols. 글씨는 시스템 폰트, 본문 16pt 이상(작은 글씨 싫어함).

### 1. `CanvasCommentSheet` — 그림에 다는 댓글창 (제일 중요)

지금은(첨부 스크린샷) 「댓글 1」 제목, 「닫기」 파란 글씨, 이름 12pt + 본문 14pt 한 줄, 기본 회색 입력칸뿐이라 **너무 성의 없어 보인다.** 둘이 서로의 그림에 남기는 다정한 한마디라는 느낌이 나게 예쁘게 바꿔 줘.

```swift
struct CanvasCommentItem: Identifiable {   // 이미 있음 — 그대로 씀
    let id: String
    let by: String      // "우댕" 또는 "꼼이"
    let text: String
    let at: Date?       // 쓴 시각 (옛 댓글은 nil일 수 있음)
}

struct CanvasCommentSheet: View {
    let comments: [CanvasCommentItem]   // 오래된 것 → 최신 순
    let myName: String                  // "우댕" 또는 "꼼이"
    let onSend: (String) -> Void        // 공백 정리된 글
    let onDelete: (String) -> Void      // 댓글 id (내 댓글만)
    let onClose: () -> Void
    var body: some View { ... }
}
```

원하는 것:
- **머리**: 「댓글」 + 개수를 작은 칩으로, 닫기는 동그란 xmark 버튼(파란 텍스트 버튼 말고).
- **댓글 한 개**: 쓴 사람 색이 보이는 작은 동그라미(이름 첫 글자 「우」/「꼼」) + 이름 + 시간 + 말풍선. 내 댓글은 오른쪽, 상대 댓글은 왼쪽 말풍선처럼 나눠도 좋고, 한 줄 카드여도 좋음 — 더 예쁜 쪽으로.
- **시간**: 「방금」 「3분 전」 「오후 9:12」(오늘) 「어제」 「10월 18일」 식으로 짧게. `at`이 nil이면 시간 없이.
- **내 댓글 지우기**: 작은 x 대신 **길게 눌러 contextMenu 「삭제」**.
- **비어 있을 때**: 「아직 댓글이 없어요」 + 「그림에 한마디 남겨 볼까?」처럼 다정한 빈 화면(SF Symbol 하나 정도).
- **입력칸**: 둥근 알약 모양, 「댓글 달기…」, 1~4줄까지 늘어남, 16pt. 보내기 버튼은 내 색으로 채운 동그라미 + `arrow.up` (빈 글이면 흐리게). 보내면 맨 아래로 스크롤.
- 새 댓글이 오면 맨 아래로 자동 스크롤.
- 시트 높이(`presentationDetents`)와 라이트 모드 고정은 내가 바깥에서 붙이니 안 넣어도 됨.

### 2. 대고 그리기 조작부 (사진 따라 그리기)

그림을 잘 못 그리는 사람이 **앨범 사진을 보드 밑에 반투명으로 깔고 그 선을 따라 그리는** 기능. 흐름:
① 사진 버튼 → 앨범에서 고름 → ② **위치 맞추기**(한 손가락으로 사진 밀기, 두 손가락으로 크기) → ③ 「잠그고 그리기」 → 사진이 고정되고 그 위에 따라 그림 → 진하기(투명도) 조절 가능. 사진은 내 폰에만 보이고 상대에겐 안 보임.

제스처·사진 고르기·메뉴는 내가 다 만들어 놨고, **보이는 조각 3개만** 예쁘게 만들어 줘:

```swift
// (a) 사진 버튼 — 보드 아래 「손바닥(이동)」 동그라미 버튼(42×42) 옆에 나란히 놓임
struct TraceButtonLabel: View {
    let active: Bool          // 사진이 깔려 있으면 true
    var body: some View { ... }   // Button/Menu의 label로만 씀 (탭 동작 넣지 말 것)
}

// (b) 위치 맞추는 중에 뜨는 패널 — 화면 아래 툴바 위
struct TraceAdjustPanel: View {
    @Binding var opacity: Double  // 0.1 ... 0.9
    let onCancel: () -> Void      // 사진 빼고 취소
    let onLock: () -> Void        // 잠그고 그리기
    var body: some View { ... }
}

// (c) 잠근 뒤 작게 남는 막대 — 툴바 바로 위
struct TraceBar: View {
    @Binding var opacity: Double  // 0.1 ... 0.9
    let onUnlock: () -> Void      // 자물쇠 누르면 다시 위치 맞추기
    var body: some View { ... }
}
```

- (b)에는 짧은 안내(「사진을 밀어서 옮기고, 두 손가락으로 크기를 맞춰요」 정도) + 진하기 슬라이더 + 「취소」 + 눈에 띄는 「잠그고 그리기」(자물쇠 아이콘).
- (c)는 작고 조용하게: 잠김 표시 자물쇠(누르면 풀림) + 진하기 슬라이더. 그림 그리는 데 방해 안 되게.
- 진하기 슬라이더 양 끝 아이콘으로 「연하게 ↔ 진하게」가 보이게.
- 휴대폰 세로(폭 375~430)와 아이패드 오른쪽 세로 툴바 옆 둘 다에 어울리게 — (b)는 최대 폭 340 정도.

세 파일로 나눠도 되고 한 파일이어도 됨. 각 뷰는 위 시그니처 그대로(이름·인자 바꾸지 말 것).
