## 무엇을 보나

꼼이(우댕의 여자친구)가 만성 두드러기 때문에 매일 적는 「꼼이 피부 일지」. 1차 검수(어제) 뒤로 이렇게 바뀌었다. **새로 들어간 것이 매일 쓰기에 편한지, 말이 알아들을 만한지, 깨지는 데가 없는지**를 본다.

1. **달력** — 기록 화면 맨 위 7일 띠의 머리(「2026년 10월 ▾」)를 누르면 한 달 달력으로 펼쳐진다. ‹ › 로 지난달, 아무 날이나 골라 그날 기록으로.
2. **모아보기** — 달력 오른쪽 위 「모아보기」. 하루하루를 보고서처럼 이어 본다(최근 2주 · 이번 달 · 지난달 · 3개월 · 전체, 요약, 주 묶음, 「이날 고치기」).
3. **칸 펼침** — 날을 열면 **적힌 게 있는 칸만 펼쳐진 채**, 빈 칸은 접힌 채. 접이식 칸 묶음 위 오른쪽 「모두 펼치기 / 모두 접기」.
4. **우댕 폰(보기 전용)** — 입력 폼 대신 **읽기 카드** 한 장. 칸을 열 필요 없이 그날 적힌 게 다 보이고, 안 적은 칸은 이름만 한 줄.
5. **하루 기록 폼 3판** — 점수와 약을 첫 화면에, 잠은 시간 칩(4~9) + 0.5 조정, 스트레스는 안 적었으면 「안 적음」.
6. **분석 화면 2판** — 「최근 7일 점수 합」에 구간 위치·이름, 30일 그래프 범례·0점과 기록 없음 구분, 「n번 비교」, 의심 요인 표 머리·생리 묶음.
7. **저장 안전** — 저장을 안 누르고 날을 바꾸거나 뒤로 가도 저장, 앱을 내려도 저장.

## 🧪 「연습 모드」로 한다 — 실제 기록은 하나도 안 보인다

주소: **https://kkommorning-v2.vercel.app/?practice=1**

연습 모드에서 피부 일지는 **지어낸 예시 기록 24일치**(9월 28일 ~ 10월 20일, 오늘 10월 21일은 비어 있음)로 열리고 PIN을 묻지 않는다. 저장·사진·설정은 이 탭에만 남고(새로고침하면 처음으로), 서버로 아무것도 안 간다.

**맨 먼저 확인:** 홈에서 「피부 일지」 카드를 누르면 기록 화면 아래쪽에 노란 띠 **「🧪 연습 모드 — 예시 기록이에요 · 저장·사진·상담이 실제로 안 나가요」**가 보여야 한다.
→ **띠가 안 보이면 즉시 멈춰라.** 아무것도 누르지 말고 스크린샷과 함께 "띠 없음"으로 보고.
→ PIN 숫자판이 보여도 즉시 멈추고 보고.

### 🚨 절대 금지 (연습 모드가 막지 않는 곳)
- **홈 화면**의 하트·범프·기분·선물·아래 퀵메시지 바 — 누르면 꼼이 폰에 진짜로 간다.
- 꼼톡·편지·칭찬·달력 등 **피부 일지 밖 화면**에서 무언가 쓰거나 보내기.
- 로그아웃. 주소에서 `?practice=1`을 빼고 들어가기(빠졌으면 위 주소로 다시 들어와 띠부터 확인).
- 사진 올리기에서 **실제 파일을 고르지 마라**.
- 상담 화면에서 보내기는 해도 되지만(정해진 안내 문장만 나온다) 이번엔 안 봐도 된다.

### ✅ 해도 되는 것 (띠가 보일 때, 피부 일지 안)
기록 화면·달력·모아보기·분석의 모든 칸 누르기·쓰기·펼치기·저장, 날 바꾸기, 「힘든 날 우댕에게 알리기」 스위치.

## 현재 상태 (코드로 확인함 — 묻지 않는다)

| 묻지 않을 것 | 이미 아는 답 |
|---|---|
| 보이는 숫자·메모 | 전부 지어낸 예시 |
| 보기 전용 흉내 | 주소 `?practice=1&view=1`, 끄기 `&view=0` (탭 안에서 기억됨) |
| 디자인 | 제미나이 시안 그대로. 「예쁘다/아니다」보다 **쓰기 불편한 곳·헷갈리는 말·깨짐**을 찾아 줘 |
| 초진 설문 화면 | 아직 없음. 보지 않는다 |
| 백업·메일 | 서버에서 매일 밤 돈다. 화면엔 없다. 보지 않는다 |
| 아이폰 상태바 자리 | 브라우저로는 재현 안 됨 |

**창 크기 두 가지:** ① 휴대폰 폭(목표 390px, 모바일 흉내가 있으면 그걸로) ② 평소 컴퓨터 크기. 보고에 **실제 창 폭(px)**. 가능하면 다크 모드도 한 번.

## 할 일

### A. 30초 기록 (가장 중요)
오늘(10월 21일)에서 「팽진 보통 + 가려움 약간 + 항히스타민 먹음 + 저장」까지 **몇 번 눌렀고 몇 초**. 「오늘은 증상 없음」으로 끝내는 경우도 한 번. 점수와 약이 **스크롤 없이 첫 화면**에 같이 보이는지.

### B. 칸 펼침
- 예시 기록이 있는 날(예: 10월 19일)을 열면 적힌 칸만 펼쳐져 있는지, 빈 칸은 접혀 있는지. 빈 오늘(21일)은 다 접혀 있는지.
- 「모두 펼치기」→ 다 펼쳐지고 글자가 「모두 접기」로 바뀌는지. 날을 바꾸면 다시 적힌 칸 기준으로 돌아가는지.
- 우댕 입장에서 「하나하나 열기 불편」이 풀렸는지 `[의견]`.

### C. 달력
- 머리 누르면 한 달로 펼쳐지고 다시 누르면 접히는지. 10월 1일이 목요일 칸에 있는지.
- ‹ 로 9월 → 9월 29일 고르기 → 주 띠가 그 주변 날로 바뀌고 아래 기록이 그날로 바뀌는지. › 는 이번 달에서 막히는지. 오늘 이후 날은 못 고르는지.
- 아래 범례 한 줄(진할수록 점수 높음 · ✓ · ✕ · 시계 · 점선 기록 안 함)이 설명 없이 읽히는지.

### D. 모아보기
- 범위 칩 5개를 차례로: 숫자(기록한 날 n/N일, 평균 점수, 힘든 날, 약 거른 날, 붓기, 자주 적은 의심 요인)가 바뀌는지, 뜻이 바로 읽히는지.
- 주 묶음 머리(「10/12 ~ 10/18 · 기록 n일 · 점수 합 n」)가 월~일로 맞는지, 기록 없는 날이 한 줄로 묶이는지.
- 하루 카드: 적힌 것만 보이고 「안 적은 칸: …」 줄이 이해되는지. 「이날 고치기」 → 그날 기록 화면으로 가는지.
- 「3개월」「전체」에서 긴 목록 스크롤이 버벅이지 않는지.

### E. 우댕 폰 보기 (`?practice=1&view=1`)
- 기록 화면 아래가 입력 폼이 아니라 **읽기 카드**인지(제목 「꼼이가 적은 기록」). 10월 19일을 골라 그날 적힌 게 다 보이는지.
- 모아보기에서 「이날 고치기」가 **안 보이는지**(보기 전용이라). 끝나면 `?practice=1&view=0`.

### F. 분석 화면 2판 (오른쪽 위 「분석」)
- 「최근 7일 점수 합 · 0~42」: 숫자 옆 구간 이름 칩, 막대 위 현재 위치 표시가 맞는 자리인지. 눈금 숫자(0·6·15·27·42)가 막대 구간과 맞는지.
- 30일 그래프: 범례, 0점 날과 기록 없는 날이 구분되는지, 날짜 아래 월 표시.
- 「약 거른 다음날 / 먹은 다음날」: 「n번 비교」와 「원인이라는 뜻은 아니에요」 문장. 겁주는 느낌이 줄었는지 `[의견]`.

### G. 저장 안전
- 오늘 칸 몇 개를 바꾸고 **저장 안 누른 채** 달력에서 다른 날로 → 다시 오늘로: 바꾼 게 남아 있는지.
- 바꾸고 저장 안 누른 채 ← 뒤로(홈) → 다시 피부 일지: 남아 있는지.

### H. 깨짐·잘림·버그
390px에서 가로로 밀리는 곳, 글자 잘림, 겹침(노란 띠·저장 막대·달력), 콘솔 오류, 다크 모드에서 안 보이는 글자.
