# Aside 의뢰서 1부 — 꼼모닝 채팅(꼼톡) 처음 써 보기

> Teo 먼저 읽기 (⚠️ 개인정보·부작용 — 맡길지 Teo가 판단)
> - Aside가 **우댕 계정으로 로그인**하면 두 사람의 실제 대화가 외부 브라우저를 지나간다.
> - 채팅창을 **여는 것만으로** 실데이터가 바뀐다: 꼼이 메시지가 **읽음**으로 바뀌고, 꼼이 화면에 우댕이 **"지금 함께"(접속 중)**로 뜬다. 꼼이도 앱을 켜 둔 상태면 **꼼이 쪽 채팅창이 자동으로 열린다.**
>   → 꼼이가 앱을 안 쓰는 시간에 돌리거나 미리 말해 두기. (읽기 전용 시험 계정을 만들면 이 문제가 사라진다 — 아직 없음)
> - 로그인 코드는 이 문서에 쓰지 않는다. Aside Vault 자동 채우기로.
> - 이 1부에는 **내 진단을 일부러 안 넣었다.** 진단을 먼저 주면 그 틀 안에서만 보고 동의만 돌아온다(관제탑 교훈). 1부 보고를 받은 뒤 2부(`aside-chat-keyboard-review-2.md`)를 보낸다.

## 너의 역할

너는 **이 커플 앱을 오늘 처음 받은 사람**이다. 애인이 "우리 둘만 쓰는 앱이야, 여기서 톡해" 하고 깔아 줬다. 아무 설명도 못 들었다. 카카오톡은 매일 쓴다.

## 현재 상태 (코드로 확인함 — 너에게 묻지 않는다)

| 묻지 않을 것 | 이미 아는 답 |
|---|---|
| 이모티콘 그림을 누르면 왜 바로 가나 | 일부러. 카톡처럼 한 번에 보낸다 (그래서 아래에서 누르지 말라고 한다) |
| 컴퓨터에서 Enter | 곧바로 보내기. 휴대폰에선 줄바꿈 |
| 대화는 어디에 저장되나 | 서버. 두 사람이 실시간으로 같이 본다 |
| 채팅 테마는 어디에 저장되나 | 이 브라우저 안에만. 바꿔도 상대에겐 안 보인다 |
| 아이폰 앱에서만 생기는 문제 | 이 브라우저로는 재현할 수 없다. 묻지 않는다 |

## 🚨 절대 금지 (상대에게 실제로 간다 — 되돌릴 수 없다)

- **보내기 0번.** 메시지·사진·이모티콘·하트·선물·음성·타임캡슐 모두. 보내기 버튼, 이모티콘 그림, 입력줄 위에 뜨는 추천 이모티콘 그림을 **누르지 마라.**
- **채팅 입력칸에 글자를 치지 마라.** 컴퓨터에선 Enter가 곧 전송이고, 치는 동안 상대 화면에 "입력 중…"이 뜬다. 입력칸은 **클릭만** 한다.
- 메시지 메뉴의 **삭제·수정·책갈피 저장** 금지.
- 이미지를 끌어다 놓거나 붙여 넣어 "이 사진을 보낼까요?"가 뜨면 **반드시 '취소'**.
- 로그아웃 금지(다시 들어오기 번거롭다). 홈 화면의 하트·범프·기분·선물 버튼 금지.

## ✅ 해도 되는 것 (마음껏 눌러 봐라 — 상대에게 안 간다)

- 메시지 목록 위아래로 스크롤, 맨 위까지 올려 보기
- 입력줄 왼쪽 ＋, 오른쪽 ☺ 를 **열고 닫기**, 그 안의 탭 넘겨 보기
- 입력칸 **클릭**(포커스)
- 메시지를 길게 누르기/우클릭 → 나온 메뉴 **보기만** 하고 바깥을 눌러 닫기 ('복사'는 눌러도 됨)
- 채팅 맨 위 오른쪽 아이콘들 열어 보기. **테마는 골라 봐도 된다**(이 브라우저에만 저장)
- 대화 속 유튜브·인스타 링크 카드 누르기(새 탭으로 열림)
- 채팅을 닫았다 다시 열기

## 할 일

### A. 입력줄
1. 채팅을 열고 입력칸을 클릭한다. 입력줄 주변에서 **눈에 걸리는 것**(가려짐·빈칸·겹침·흔들림)을 전부 기록.
2. ＋ 를 열었다 닫고, ☺ 를 열었다 닫는다. 그때마다 **입력칸·메시지가 어디로 가는지** 기록.
3. 휴대폰 폭에서 **화면 키보드(가상 키보드)를 띄울 수 있으면** 띄워서 1·2를 반복. **못 띄우면 "못 봄".**

### B. 처음 쓰는 사람의 눈
다음을 **어떻게 할지 찾기만** 한다(실행 금지, 버튼 위치를 찾은 데서 멈춤):
사진 보내기 / 이모티콘 보내기 / 음성 보내기 / 미래에 도착하는 메시지 보내기 / 특정 메시지에 답장하기 / 지난 대화 중 소중한 것 모아 보기.
각각 **몇 번 눌러서 찾았나, 어디서 몇 초 멈췄나, 화면 글자 그대로** 기록. 못 찾으면 "못 찾음".

## 기록 규칙

- 본 것만 적어라. 못 본 것은 "못 봄"이라고 적어라. 추측하지 말 것.
- 화면 문구는 그대로 옮겨라. 요약하지 말 것.
- "괜찮네요" 같은 말은 쓸모없다. 어디서 몇 초 멈췄는지가 필요하다.
- 판단이 안 서면 멈추고 "여기서 멈췄다"고 적을 것.
- "○○ 기능이 없다"고 쓰고 싶으면 "○○을 못 찾았다"로 쓸 것.
- 단계마다 스크린샷 1장 이상.
