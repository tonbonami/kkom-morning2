## 이야기

둘만의 구호 「냥냥! 의기냥냥!」(「의기양양」 말장난) — 뭔가 다짐할 때 외친다. **결의에 찬 모습**이 핵심이고, 끝에 작은 사고가 나도 표정은 끝까지 뿌듯하고 당당하다.
- 꼼이: 고양이처럼 앞발을 들고(1) → 냥냥 펀치 두 번(2) → 가슴 펴고 뿌듯한데 늘어진 귀가 코앞에 찰싹(3).
- 꿀댕이: 돌진 직전처럼 버티며 고양이 발짓(1) → 고개 번쩍 외침, 더듬이 V자(2) → 뿌듯한데 더듬이 방울 둘이 머리 위에서 콩 하이파이브(3).
영상 A = 1 → 2, 영상 B = 2 → 3. 편집에서 이어 붙인다.
