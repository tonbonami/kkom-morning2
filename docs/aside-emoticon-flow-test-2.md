## 바뀐 것
1차 검수(아까 네가 T1~T11 통과시킨 것) 뒤 우댕이 「내사랑 꼼슌이 보고싶어」에서 보고싶어를 고르면 카톡은 문장이 다 가는데 꼼톡은 「보고싶어」를 지웠다고 했다. 그래서:
- 입력칸에 **뜻 있는 낱말이 하나뿐**(꾸밈 ~ ! ? ♥ 이모지 ㅋㅋ ㅎㅎ ㅠㅠ는 셈에서 뺌)일 때만 고른 이모티콘이 그 말을 **대신**한다(입력칸 비움).
- **문장이면 글은 하나도 안 지운다** — 문장 + 이모티콘이 한 메시지로.
- 미리보기 카드 아래 한 줄: 대신하면 「‘사랑해’ 대신 보내요」, 문장이면 「글은 그대로 두고 함께 보내요」. 서랍 결과 위 분홍 안내도 「고르면 입력한 「…」 대신 가요」/「고르면 입력한 글과 함께 가요」.
- 네 1차 의견도 반영: 검색 결과에서 **글 속 미니는 맨 뒤 「글 속 미니 — …」 칸에 따로**, 결과 순서는 서랍을 열 때 고정, **보낸 뒤엔 검색칸이 비고** 평소 탭 화면.

## 들어가는 법
`https://kkommorning-v2.vercel.app/?practice=1` → 강력 새로고침 → 꼼톡. 노란 띠 확인.
새 코드 확인: 「사랑해」를 치고 작은 그림 → 서랍에 「글 속 미니」 칸이 따로 보이면 새 코드. 아니면 새로고침 한 번 더, 그래도 아니면 멈추고 보고.

## 해 볼 것 (하나마다 화면을 찍어 artifacts에 저장)

|---|---|---|
| U1 | 「내사랑 꼼슌이 보고싶어」 → 입력칸 작은 그림 → 서랍 | 분홍 안내가 「고르면 입력한 글과 함께 가요」인지 |
| U2 | 결과 위쪽(미니 아닌) 하나 고름 | 입력칸에 「내사랑 꼼슌이 보고싶어」가 **그대로** 있는지 · 카드 아래 「글은 그대로 두고 함께 보내요」 |
| U3 | 보내기 | 연습 모드 토스트 · 그 뒤 서랍 검색칸이 비었는지(평소 탭 화면) |
| U4 | 입력칸 비우고 「사랑해~~」 → 작은 그림 → 서랍 | 검색칸이 「사랑해」(물결 뗀 것)인지 · 분홍 안내 「고르면 입력한 「사랑해」 대신 가요」 |
| U5 | 미니 아닌 것 하나 고름 | 입력칸이 비는지 · 카드 아래 「‘사랑해’ 대신 보내요」 |
| U6 | 미리보기 ✕ | 입력칸에 「사랑해~~」가 그대로 돌아오는지 |
| U7 | 입력칸 비우고 「배고파 ㅠㅠ」 → 작은 그림 → 하나 고름 | 입력칸이 비는지(ㅠㅠ는 꾸밈) · 「‘배고파’ 대신 보내요」 · 그다음 ✕로 되돌리기 |
| U8 | 입력칸 비우고 「잘자 꿈꿔」 → 작은 그림이 뜨면 → 하나 고름 | 글이 그대로 남는지 (작은 그림이 안 뜨면 「안 뜸」이라고 적기) |
| U9 | 입력칸 비우고 「행복」 → 작은 그림 → 서랍 | 결과에서 미니가 맨 뒤 「글 속 미니」 칸에 따로 있는지 · 그 미니를 누르면 입력칸이 「(행복)」 |
| U10 | 입력칸 비우고 「꼼슌아 사랑해」 → 작은 그림 → 「글 속 미니」에서 하나 누름(있으면) | 입력칸이 「꼼슌아 사랑해 (…)」처럼 문장 끝에 붙는지 (미니가 없으면 「미니 없음」) |

끝나면 입력칸을 비우고 꼼톡을 닫는다.
