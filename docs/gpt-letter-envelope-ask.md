## 회의 안건 (중요한 순서)
1. **「처음」의 정의와 기록** — 받은 사람이 그 편지를 처음 열 때만 봉투를 보여 주려면 무엇을 어디에 저장해야 하나(편지 문서에 칸? `letterReads` 확장? 기기 localStorage?). 두 기기(폰·워치·데스크톱)에서 겹칠 때, 보낸 사람이 자기 편지를 열 때, 예약편지가 도착한 직후, 옛 편지(이미 읽은 것)는 어떻게.
2. **봉투 순간의 순서와 길이** — 내용이 가려진 상태 → 열림 → 편지가 나와 펼쳐짐. 누르면 열리기 vs 저절로, 총 몇 초, 건너뛰기, 진동, 편지지 색(6장)과 봉투·밀랍 도장 맞추기, From 도장, `prefers-reduced-motion`. 「확 열리는」 시원함과 「약간의 애니메이션」 절제 사이 균형.
3. **귀퉁이 생각풍선(꿀됑·꼼이)** — 언제(봉투 단계만? 읽는 내내?), 누가 어느 귀퉁이, 풍선 안 그림 고르는 법(보낸 사람·받는 사람, 편지 속 미니·큰 이모티콘과 연결? 고정?), 움직임(둥실·꼬리 동그라미), 글 읽기를 방해하지 않는 크기·위치. 지금 있는 그림으로 되는지, 새 그림(ChatGPT)이 필요한지.
4. **목록·홈과의 연결** — 안 읽은 편지는 목록·홈 카드에서 봉투 모양으로 보이게 할지.
5. **웹뷰 성능·위험** — framer-motion 11, 저사양 아이폰, 큰 움짤 webp(최대 1.4MB)와 동시에 돌 때.
6. **단계 나누기** — 1차에 꼭 할 것 / 2차로 미룰 것.
7. **Gemini 디자인 의뢰서 초안** — 만들 컴포넌트, props(이름·타입), 상태(가려짐→여는 중→열림), 금지 사항.
