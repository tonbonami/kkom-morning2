## 무엇을 보나

꼼이(우댕의 여자친구)가 만성 두드러기 때문에 매일 적는 「꼼이 피부 일지」. 2차 검수 뒤로 고친 것과 **새로 들어간 「오늘 상담 정리하기」**를 본다.

**새 기능 — 오늘 상담 정리하기:** 꼼이가 Claude와 상담한 뒤 상담 화면의 「✨ 오늘 상담 정리하기」를 누르면, 그날 상담을 정리해 보여 준다(핵심 · 꼼이가 말한 것 · 걱정과 질문 · 해 보기로 한 것 · Claude가 설명·제안한 것(참고)). 그 아래 **「일지에 반영할까요?」** 후보(꼼이가 직접 말한 사실만)를 켜고 끄고, ✏️로 고치고(예: 약 3알 → 2알), 날짜가 애매한 건 날짜를 고르고, 일지에 이미 다른 값이 있으면 「바꾸기 / 메모로만」을 고른 뒤 **「선택한 내용을 일지에 반영」**. 「다음 상담에도 기억할 것」에서 켠 것만 Claude가 다음 상담부터 기억한다.

**2차 검수 뒤 고친 것:** 점수와 약(먹음·늦게·거름)이 첫 화면에 · 약 줄에 「용량」 칸 · 달력 「오늘」 버튼·범례 한 줄 · 분석 화면(빈 날은 평균으로 채운 값 안내, 기록 없는 날 빈 동그라미, 「아직 n번뿐」) · 기록 화면 머리에 「상담」 바로가기 · 연습 띠가 맨 위로 · 우댕 폰 상담 화면에 「Claude 사용량」 카드.

## 🧪 「연습 모드」로 한다 — 실제 기록은 하나도 안 보인다

주소: **https://kkommorning-v2.vercel.app/?practice=1**

연습 모드에서 피부 일지는 **지어낸 예시 기록**(9월 28일 ~ 10월 20일, 오늘 10월 21일은 비어 있음)으로 열리고 PIN을 묻지 않는다. 저장·사진·설정은 이 탭에만 남고(새로고침하면 처음으로), 서버로 아무것도 안 간다. 상담은 실제 Claude 대신 정해진 안내 문장, **상담 정리도 지어낸 예시 정리**(약 3알·맥주·잠 5시간 반 이야기)가 1~2초 뒤에 나온다.

**맨 먼저 확인:** 홈에서 「피부 일지」 카드를 누르면 기록 화면 **맨 위**에 노란 띠 **「🧪 연습 모드 — 예시 기록이에요 · 저장·사진·상담이 실제로 안 나가요」**가 보여야 한다.
→ **띠가 안 보이면 즉시 멈춰라.** 아무것도 누르지 말고 스크린샷과 함께 "띠 없음"으로 보고.
→ PIN 숫자판이 보여도 즉시 멈추고 보고.
⚠️ **이번엔 새로고침(⌘R)을 하지 마라** — 연습 기록이 처음으로 돌아가 정리·반영 확인이 꼬인다. 화면 이동은 앱 안의 버튼(←, 상담, 분석, 모아보기)으로만.

### 🚨 절대 금지 (연습 모드가 막지 않는 곳)
- **홈 화면**의 하트·범프·기분·선물·아래 퀵메시지 바 — 누르면 꼼이 폰에 진짜로 간다.
- 꼼톡·편지·칭찬·달력 등 **피부 일지 밖 화면**에서 무언가 쓰거나 보내기.
- 로그아웃. 주소에서 `?practice=1`을 빼고 들어가기.
- 사진 올리기에서 **실제 파일을 고르지 마라**.

### ✅ 해도 되는 것 (띠가 보일 때, 피부 일지 안)
기록·달력·모아보기·분석·상담·상담 정리 화면의 모든 버튼·칸·저장·반영.

## 할 일 (순서대로)

### A. 첫 화면과 약 용량
1. 기록 화면(오늘 21일): 390×844에서 스크롤 없이 「오늘 점수」와 약의 「먹음·늦게·거름」이 저장 막대에 안 가리고 보이는지.
2. 약 줄: 이름 · **용량** · 시각 · 지우기가 한 줄에 잘리지 않는지. 약 이름 「항히스타민」 그대로, **용량 「2알」**, 「먹음」, 시각 아무거나 → **저장**. (이 값이 C에서 「일지와 다름」 비교에 쓰인다)

### B. 상담 화면
1. 기록 화면 오른쪽 위 **「상담」** → 상담 화면이 바로 열리는지.
2. 입력 막대 바로 위 **「✨ 오늘 상담 정리하기」**가 잘 보이는지(대화 말풍선을 가리지 않는지). 예시 질문 칩 하나를 눌러 답(안내 문장)이 흘러나오는 것도 한 번.

### C. 상담 정리 (가장 중요)
1. 「✨ 오늘 상담 정리하기」 → 「Claude가 오늘 상담을 정리하고 있어요」 뒤에 정리 화면.
2. **정리가 일목요연한지** `[의견]`: 핵심 요약 · 꼼이가 말한 것 · 걱정과 질문 · 해 보기로 한 것 · Claude가 설명·제안한 것(참고).
3. **「일지에 반영할까요?」 후보:**
   - 약 후보에 **「일지와 다름 · 현재 일지: 항히스타민 · 2알 · 먹음」**이 보이고 「바꾸기 / 메모로만」을 고를 수 있는지.
   - 약 후보 ✏️ → 용량 「3알」을 「2알」이나 「4알」로 고치면 위 한 줄이 바로 바뀌는지.
   - 「잠 — 5.5시간」은 「짐작됨」 표시로 꺼져 있는지 → 켜면 날짜를 골라야 한다는 빨간 안내가 뜨는지 → 「어제」 고르기.
   - 「다음 상담에도 기억할 것」 켜고 끄기·✏️ 글 고치기.
   - 아래 버튼 숫자(켠 후보 + 켠 기억)가 맞는지.
4. **「선택한 내용을 일지에 반영」** → 완료 화면 → 「일지에서 보기」: 오늘(21일) 약이 고른 대로(바꾸기면 고친 용량·23:00·늦게, 메모로만이면 메모에 「[상담 정리] …」), 「의심 가는 것」에 「술」, 어제(20일) 잠 5.5시간이 들어갔는지.
5. 상담 화면으로 돌아가 버튼이 **「오늘 정리 다시 보기 ✓」**로 바뀌었는지, 눌러서 다시 볼 때 아래 안내가 「이 날 정리는 일지에 반영했어요…」인지.

### D. 2차 고친 것 다시 보기 (짧게)
- 달력: 옛날 날을 고르면 「오늘」 버튼이 생기고 누르면 오늘로. 범례 한 줄(390px).
- 분석: 「7일 중 n일 기록 · 빈 날은 평균으로 채운 값」, 그래프의 기록 없는 날 빈 동그라미와 0점 구분, 「아직 n번뿐」.
- 모아보기: 일지 시작 전 날이 빠졌는지(「지난달」 분모).

### E. 우댕 폰 보기 (`?practice=1&view=1` — 이 주소로 새로 들어가면 연습 기록이 처음으로 돌아가니 C를 다 끝낸 뒤에)
- 상담 화면: 입력 막대 대신 「보기 전용이에요 — 상담은 꼼이만 해요」, 위에 **「Claude 사용량」 카드**(오늘·이번 달·지금까지, 접기)가 이해되는지.
- 기록 화면: 사진 칸에 「추가」가 없는지, 아래가 읽기 카드인지.
- 끝나면 `?practice=1&view=0`.

### F. 깨짐·잘림·버그
390px에서 가로 밀림, 글자 잘림(특히 약 시각·용량·이름), 겹침(정리 화면 아래 고정 버튼과 마지막 카드), 콘솔 오류.
