## 내가(Claude) 생각한 방향 — 틀리면 반박해 주세요

- 달력 화면을 다이어리 월간 달력 **하나로** 모은다. 홈의 달력 카드도 다이어리로 합친다.
- `calendarEvents` 데이터와 알림 크론·꼼톡 카드는 **그대로** 둔다(옮기지 않는다).
- 다이어리 달력이 일정을 띠(여러 날)·작은 표시(하루)로 그리고, 그 위에 스티커·메모를 얹는다.
- 「기간 띠」를 붙이면 꾸미기 전용이 아니라 **진짜 일정**으로 저장한다(알림도 가능). 띠 무늬는 일정에 `decorId` 같은 선택 필드로.
- 날짜를 톡 하면 그날 일정 목록과 하루 장 들어가기가 같이 보인다.

## 정해 주세요 (각 항목: 추천안 하나 + 이유 + 버린 안)

1. **띠와 일정의 관계** — 기간 띠 = 일정으로 통일? 꾸미기 전용 띠도 남길까요? 이미 저장된 `diaryMonths.spans`(오늘 배포라 거의 없음)는 어떻게 할까요?
2. **칸 메모(7자)와 하루짜리 일정** — 둘 다 둘까요, 하나로 합칠까요? 합친다면 어느 쪽으로?
3. **주인 구분** — 일정의 owner(꼼이·우댕·함께)와 달력 세 장(같이·우댕·꼼이)을 어떻게 맞출까요? 「같이」 장에는 모든 일정? 각자 장에는 자기 일정 + 함께 일정? 상대의 개인 일정은?
4. **좁은 칸에 그리기** — 47×66px 칸에 일정 띠·하루 일정·스티커 2개·메모·기념일을 어떻게 나눠 담을까요? 줄 수 한도, 넘칠 때 표시(「+2」 등), 꾸미기 모드와 보기 모드에서 달라져야 할 것.
5. **날짜를 눌렀을 때** — 지금은 보기 모드에서 날짜 톡 = 하루 장으로 이동이에요. 합친 뒤엔 무엇이 열려야 할까요(그날 시트: 일정 목록 + 「일정 추가」 + 「하루 장 열기」)? 탭 수를 최소로.
6. **일정 추가·수정 창** — 기존 `calendar/page.tsx` 의 창을 그대로 떼어 쓸지, 다이어리 모양으로 새 시안을 받을지. 필드(시간·장소·메모·알림·주인·띠 무늬)의 기본값과 「간단히 추가」 흐름.
7. **다가오는 일정** — 기존 15일 목록과 다이어리의 「곧 … · N일」 한 줄을 어떻게 합칠까요?
8. **홈 카드** — 달력(1x1)과 다이어리(2x1)를 하나로 합친 카드에 무엇을 보여 줄까요? 저장된 홈 배치에 `calendar` 카드가 있는 사용자는 어떻게 옮길까요?
9. **옛 길 처리** — `/calendar` 주소, 알림을 눌렀을 때 가는 곳, 꼼톡 일정 카드가 여는 곳.
10. **옮기는 순서** — 한 번에 바꾸지 말고 단계로. 각 단계가 혼자서도 쓸 만해야 하고, 문제가 생기면 되돌릴 수 있어야 해요. 옛 달력은 언제 뗄까요?
11. **성능·위험** — `calendarEvents` 전체 구독을 그대로 둬도 되는지, 달 넘길 때 버벅임, 실수로 일정이 지워질 위험(지우개 도구가 일정 띠도 지우면 알림까지 사라짐) 등.
12. **1차에서 뺄 것** — 욕심내면 안 되는 것.

## 지켜야 할 것

- 폰 한 손 사용, 간단하게. 우댕 말: 「주로 폰으로 사용하니까 간단하게」, 「다꾸하는 사람들은 달력 꾸미는 것도 좋아하잖아」.
- 장부·감시 금지: 연속 기록, 「며칠째 안 씀」, 작성 횟수·비교 통계를 만들지 않아요.
- 화면 디자인은 제미나이가 그리고(시안), Claude 는 그대로 붙이기만 해요. 그래서 **제미나이에 맡길 화면·부품 목록과 각 부품이 받을 값(props)** 을 답에 꼭 넣어 주세요.
- 일정 데이터와 알림은 지금 잘 돌고 있어요. 깨뜨리지 않는 게 최우선이에요.
