핵심은 “추천이 도움이 되는 대신, 입력 흐름을 가리고 전송 결과를 예측하기 어렵게 만든다”는 데 있습니다.

### 1. 왜 불편했는지

1. 입력할 때마다 큰 추천 줄이 튀어나와 대화를 가리고 시선을 빼앗는다.
2. 이모티콘을 골랐는데 입력한 「사랑해」까지 함께 전송되어 같은 뜻이 중복된다.
3. 선택 후 한 번 더 누르기·전송 버튼 등 전송 방식이 둘이라 결과를 예측하기 어렵다.
4. 미리보기 카드가 크고 불투명하며 안내 문구까지 있어 대화 맥락을 많이 가린다.
5. 추천→서랍→미리보기 흐름이 아니라 추천 줄 안에서 선택과 전송이 섞여 있어 탐색하기 어렵다.

### 2. 계획 ①~⑦ 평가

① **좋음.** 자동 큰 추천 줄은 없애고, 사용자가 요청한 「짝 답장」에만 남기는 게 맞다.

② **좋음.** 작은 추천 그림으로 조용히 알려주는 방식이 핵심 개선이다. 추천이 없으면 원래 스마일로 돌아가야 한다.

③ **좋음.** 해당 단어의 검색 결과로 바로 연결하되, 사용자가 검색 흐름에 들어왔다는 표시를 칩이나 검색어로 보여줘야 한다.

④ **바꿀 것.** 앞 문장은 남기되 공백까지 자연스럽게 정리한다. 다만 단어 삭제는 이모티콘을 실제로 고르는 순간에만 하고, 내부적으로 복구 가능한 원문을 보관한다.

⑤ **대체로 좋음.** 일반 서랍은 사용자가 글을 이모티콘으로 “대체”하려고 연 것이 아니므로 글을 유지한다. 미리보기에서 함께 전송됨을 명확히 보여줘야 한다.

⑥ **바꿀 것.** 반투명 카드·★·✕는 좋다. 하지만 그림을 다시 누르면 즉시 전송되는 기능은 빼는 편이 안전하다. 전송은 노란 전송 버튼 하나로 통일한다.

⑦ **좋음.** 이번 개선의 핵심은 추천의 방해와 텍스트 중복 문제다. 서랍 위치 변경은 별도 작업으로 미뤄도 된다.

### 3. 경계 사례

- **「오늘도 사랑해」:** 「오늘도」를 남기는 쪽이 맞다. 선택한 이모티콘이 마지막 단어 「사랑해」를 대체하기 때문이다. 통째로 비우면 사용자가 쓴 의미까지 잃는다.
- **미리보기 ✕:** 뺀 단어를 정확히 되돌리는 게 맞다. 커서 위치와 원래 공백도 복구해야 한다.
- **다른 탭을 구경하다 선택:** 단어를 빼지 않는다. 검색 탭을 벗어난 순간 “이 단어를 대체한다”는 연결을 해제하는 것이 자연스럽다. 다시 해당 검색 결과로 돌아와 고른 경우에만 뺀다.
- **같은 그림을 한 번 더 눌러 즉시 전송:** 없애는 것을 권한다. 탐색 중 실수로 전송될 가능성이 크고, 전송 버튼과 역할이 중복된다.
- **서랍을 입력바 아래로 이동:** 이번에 필수는 아니다. 다만 장기적으로는 키보드와 자리를 교체하는 구조가 대화를 덜 가리고 카톡 경험과도 더 가깝다.

### 4. 놓치기 쉬운 디테일

- 작은 추천 그림은 “전송될 그림”이 아니라 “관련 이모티콘 서랍을 여는 단추”라는 점이 중요하다.
- 추천 경로로 서랍을 열었다는 상태는 검색어 칩 등으로 계속 보여줘야 한다.
- 미리보기 중에도 서랍은 닫히지 않아 다른 후보를 비교·교체할 수 있어야 한다.
- 다른 이모티콘을 고르면 기존 미리보기 카드를 새 선택으로 교체해야 한다.
- ✕는 미리보기 취소와 텍스트 복구만 하고, 서랍까지 닫을지는 별도 동작으로 두는 편이 자연스럽다.
- ★는 즐겨찾기 기능으로 보이지만 정확한 동작은 이미지로만은 **불확실**하다.
- 카카오톡이 여러 단어가 있는 문장에서 정확히 어느 범위까지 삭제하는지는 제공된 화면만으로는 **불확실**하다. 꼼모닝에서는 “추천에 사용한 마지막 단어만 대체” 규칙이 가장 예측 가능하다.
