## 🧪 이번엔 「연습 모드」로 한다 — 쳐 보고 눌러 봐도 된다

주소: **https://kkommorning-v2.vercel.app/?practice=1**

연습 모드에서는 꼼이에게 **아무것도 안 간다**: 메시지·이모티콘 전송, "입력 중…", 읽음 표시, 접속("지금 함께") 표시, 반응·수정·삭제·별표, 링크 저장이 모두 막힌다. 막힐 때마다 아래쪽에 **"🧪 연습 모드 — … 안 보냈어요"** 토스트가 뜬다.

**맨 먼저 확인:** 채팅(홈 오른쪽 위 말풍선 아이콘 「꼼톡」)을 열면 이름 바로 아래에 노란 띠 **"🧪 연습 모드 — 무엇을 눌러도 꼼이에게 안 가요"** 가 보여야 한다.
→ **띠가 안 보이면 즉시 멈춰라.** 입력칸에 글자를 치지 말고, 이모티콘도 누르지 말고, 스크린샷과 함께 "띠 없음"으로 보고하고 끝낸다.
→ 띠가 보여도, 처음 이모티콘을 하나 눌렀을 때 "안 보냈어요" 토스트가 안 뜨고 대화에 새 말풍선이 생기면 **즉시 멈추고** 보고한다.

### 연습 모드가 켜져 있어도 🚨 절대 금지 (연습 모드가 막지 않는 곳)
- **홈 화면**의 하트·범프·기분·선물·아래 퀵메시지 바(보고싶어/사랑해/뽀뽀/잘 자) — 누르면 꼼이 폰에 진짜로 간다.
- 편지·칭찬·달력 등 **채팅 밖 화면**에서 무언가 쓰거나 보내기.
- 로그아웃.
- 새 탭이나 주소를 바꿔 `?practice=1` 없이 들어가지 마라. 주소가 바뀌었으면 다시 위 주소로 들어오고 띠부터 확인.

### ✅ 해도 되는 것 (채팅 안, 띠가 보일 때)
- 입력칸에 글자 치기·지우기, Enter, 보내기 버튼.
- ☺ 이모티콘 서랍 열기·닫기, 탭 넘기기, **이모티콘 눌러 보기**(보내는 흐름을 끝까지 보라).
- 입력줄 위에 뜨는 **추천 이모티콘 줄** 눌러 보기·✕ 닫기.
- ＋ 열기, 테마 바꾸기(이 브라우저에만 저장), 추억 보관함 열기.
- 다 하고 나면 입력칸을 비워 둔다.

## 현재 상태 (코드로 확인함 — 너에게 묻지 않는다)

| 묻지 않을 것 | 이미 아는 답 |
|---|---|
| 서랍(☺) 탭 순서·개수 | 최근·자주 / 움짤 24 / 말티푸 16 / 기본 12(표정) / 우댕 4 / 꼼이 6 / 커플 24 / 미니 21 / 꿀됑 16 / 꿀됑 움짤 4 |
| 인물 | **우댕**(지금 네 계정)의 캐릭터 = 꿀됑(꿀벌옷 아기돼지)·우댕 탭. **꼼이**(애인)의 캐릭터 = 말티푸(흰 강아지)·꼼이 탭 |
| 이모티콘을 누르면 왜 바로 가나 | 지금은 일부러 카톡처럼 한 번에 보낸다. "미리 보고 보내기"가 나은지는 네 의견으로 따로 적어라 |
| 「미니」 탭 | 눌러도 바로 안 가고 입력칸에 `(단어)`로 들어간다 → 글과 함께 보내면 말풍선 안에 작은 그림 |
| 「최근·자주」 | 이 브라우저(기기)에만 기록된다. 연습 모드에서도 기록은 쌓인다 |
| 추천 줄의 원리 | 지금 치는 단어로 찾는다. 자음 하나(ㄱ·ㅂ·ㅈ…)·초성(ㅂㄱㅍ)·같은 뜻 말(배고파=꼬르륵)까지. 보내는 사람 캐릭터를 살짝 앞에. ✕를 누르면 지금 단어에선 다시 안 뜨고, 다음 단어부터 다시 뜬다 |
| 아이폰 앱에서만 생기는 일(키보드·커서) | 이 브라우저로는 재현 불가. 묻지 않는다 |

**창 크기 두 가지로 각각 본다:** ① 휴대폰 폭(목표 390px, 모바일 흉내 기능이 있으면 그걸로), ② 평소 컴퓨터 크기. 보고에 **실제 창 폭(px)**을 적어라.

## 할 일

### A. 서랍으로 찾기 — 시간을 재라
아래 다섯 상황마다 **☺를 연 순간부터 원하는 걸 누를 때까지** 몇 번 눌렀고 몇 초 걸렸는지, 어느 탭에서 헤맸는지 기록. (네 계정 = 우댕, 애인 = 꼼이)
1. 퇴근길에 "가는 중"
2. 배고프다
3. 잘 자
4. 미안해
5. 꼼이를 응원(힘내)

그리고:
6. 탭 이름 10개만 보고 각 탭에 뭐가 있을지 **열기 전에** 짐작해 적고, 열어 본 뒤 맞았는지. (특히 「기본」「미니」「커플」「말티푸」「꿀됑」)
7. 탭이 10개인 게 많은가. **합치거나 나누거나 순서를 바꾸면** 어떻게 할지 네 안(案)을 표로.
8. 「최근·자주」 탭: 몇 개 보낸 뒤 다시 열었을 때 쓸모 있게 바뀌나.
9. 움짤(움직이는 것)과 정지 그림이 서랍에서 구분되나.

### B. 추천 줄 — 쳐 보고 기록
아래 말을 **하나씩 쳐서**(치고 나면 지운다) 추천 줄에 뜬 그림 수·첫 번째 그림 이름(그림 위 글씨)·"원하던 게 몇 번째였나"를 표로:
`ㄱ` `ㅂ` `ㅈ` `ㅋㅋ` `배고` `가는중` `출근` `잘자` `사랑해` `미안` `힘내` `졸려` `뽀뽀` `보고싶어` `헐` `오늘 점심 뭐 먹지` `나 이제 퇴근해`
- 추천 줄이 **너무 자주 떠서 거슬리는** 때가 있나(긴 문장 칠 때 등). 반대로 떠야 하는데 안 뜬 때.
- 추천 줄이 대화 내용을 가리나. ✕ 닫기가 원하는 대로 동작하나.
- 추천 그림을 누르면: 쳐 둔 글자는 어떻게 되나(남나·지워지나), 그게 자연스러운가. 카톡은 어떻게 하는지와 비교.

### C. 벤치마킹 — 카카오톡·라인·위챗
**지금 시점의 실제 기능**을 조사해서(웹 검색·공식 도움말·스토어 설명 — 출처 링크 필수), 이모티콘 고르기·보내기 쪽에서 세 앱이 가진 것 중 **둘만 쓰는 커플 앱**에 맞는 것을 골라라. 예를 들어 이런 걸 확인해 봐(이 목록에 없는 것도 좋다):
- 이모티콘 검색창 / 즐겨찾기(★) / 최근 줄
- 보내기 전 크게 미리보기 → 한 번 더 눌러 전송(카톡), 길게 눌러 미리보기
- 글자 + 이모티콘 한 말풍선에 같이 보내기
- 키워드 자동 추천의 동작(뜨는 시점·자리·닫기·끄기 설정)
- 받은 이모티콘을 눌러 "나도 이거" 바로 쓰기 / 같은 걸로 답하기
- 이모티콘으로 메시지에 반응, 큰 이모지(이모지만 보내면 크게)
- 위챗 「拍一拍(톡톡 두드리기)」, 라인·카톡의 말풍선 효과·애니메이션 반응 같은 **둘 사이 장난 기능**
각 항목: 어느 앱에 어떻게 있나(출처) → 꼼톡에 지금 있나(직접 확인) → 넣으면 좋을지·이유.

### D. 꼼톡 전체에서 더하거나 고칠 것
이모티콘 밖이라도 채팅을 써 보며 걸린 것, 세 앱과 비교해 **둘이 쓰기에 아쉬운 것**.
