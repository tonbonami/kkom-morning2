꼼모닝 네이티브 앱

더 할 수 있는 것 · 상세 개선 로드맵

2026년 7월 31일 · 현재 build 3(v1.0) 기준 · iOS TestFlight 배포 중
우댕 ♥ 꼼이 · 호평동 ↔ 서울 중구

1 한눈에

웹(PWA)에는 이미 편지·칭찬·추억·위시·또갈래·라이브하트·달력·낙서장까지 다 있어요. 그래서 이 리포트는 “네이티브 껍데기여야만 할 수 있는 것”에만 집중합니다. 웹으로 이미 되는 걸 또 만들자는 얘기가 아니라, 아이폰이라서 가능한 초능력을 더하는 로드맵이에요.

임팩트 #1

🔔 진짜 알림 (APNs)

웹푸시는 iOS에서 잘 안 와요. 네이티브 APNs면 “꼼이 방금 접속”, “낙서 남김”, 미세먼지 나쁨 경보가 확실히 도착. 앱을 ‘열어봐야 아는 것’에서 ‘먼저 알려주는 것’으로.

임팩트 #2

🏝️ 라이브 액티비티

둘 다 접속 중이면 잠금화면·다이나믹 아일랜드에 실시간 하트/접속 상태가 떠요. 앱을 안 열어도 “지금 같이 있다”가 느껴지는 기능.

임팩트 #3

✏️ 낙서장 고도화

Apple Pencil 필압, 상대 펜 커서 생중계, 스티커·사진 붙이기, 획 리플레이, 그릴 때 햅틱. 커플 낙서장을 네이티브급으로.

2 지금 앱에 있는 것 (as-is)

이미 만들어 둔 것들. 새 아이디어가 이것들과 겹치지 않도록 정리해 둡니다.

공통(웹+네이티브)

접속 상태(presence)D-day공유 달력 날씨·미세먼지기분(mood)편지 + 움직이는 스티커 칭찬추억위시리스트또 갈래 라이브 하트시집레시피웹푸시(아침 발송)

네이티브 전용(현재)

낙서장 (UIKit 커스텀 캔버스)홈 위젯 (WidgetKit) Face ID 잠금RTDB 실시간 동기화앱 아이콘·딥링크

→ 네이티브의 강점은 낙서장 · 위젯 · 실시간. 아래 로드맵은 이 축을 키우고, 아이폰만 되는 알림·잠금화면·펜·위치·시계·햅틱을 새로 엽니다.

3 3단계 로드맵

임팩트 대비 품이 적은 순서로. Phase 1만 해도 앱 체감이 확 달라집니다.

Phase 1 — “먼저 알려주는 앱” · 1~2주 체감, 가장 큰 변화

  • APNs 푸시 — 접속 알림, 낙서 알림, 미세먼지 나쁨 경보, 아침·밤 인사
  • 위젯 인터랙션 — 위젯에서 바로 하트 보내기(iOS 17 App Intents)
  • 낙서 썸네일 위젯 — 최근 낙서를 4×4 위젯에 그려서 표시
  • 햅틱 — 하트 받을 때 진동, 낙서 그릴 때 촉감

Phase 2 — “같이 있는 느낌” · 잠금화면·펜·시계

  • 라이브 액티비티 / 다이나믹 아일랜드 — 둘 다 접속 중 실시간 표시
  • 낙서장 실시간 커서 — 상대 펜 위치가 내 화면에 움직임
  • Apple Pencil 필압·기울기, 스티커·사진 붙이기, 획 리플레이
  • StandBy·잠금화면 위젯 확장 (충전 중 탁상시계처럼)

Phase 3 — “멀리 있어도” · 위치·시리·워치

  • 도착 알림(Geofence) — 상대가 집/회사 도착하면 조용히 알림 (떨어져 사는 커플용)
  • Siri·단축어 — “꼼이 접속했어?”, “오늘 낙서 보여줘”
  • Apple Watch 앱 — 손목에서 접속 확인·하트·낙서 알림
  • 오늘의 사진 · 위젯 슬라이드쇼, iCloud 백업

4 아이디어 상세

각 아이디어마다 무엇을 · 왜 우리한테 좋은지 · 어떻게 구현을 담았어요. 뱃지: 우선 높음 중간 낮음 · 난이도 ★ · 꼼이 우선

A. 알림 — 앱이 먼저 말 걸기

🔔 네이티브 푸시(APNs) 기반 만들기 우선 높음난이도 ★★

웹푸시는 iOS PWA에서 권한·전달이 불안정해요. 네이티브 앱에 Firebase Cloud Messaging(APNs)을 붙이면 모든 알림이 확실하게 도착합니다. 아래 알림들의 공통 토대라 제일 먼저.

구현: FirebaseMessaging 추가 → UNUserNotificationCenter 권한 → APNs 토큰을 RTDB tokens/{user}에 저장 → 기존 Vercel cron(아침 발송 로직)에서 web-push 대신/함께 FCM 전송. Capacitor PushNotifications 플러그인으로도 가능.

🌫️ 미세먼지 나쁨 경보 꼼이 우선우선 높음난이도 ★★

꼼이가 제일 신경 쓰는 미세먼지. 서울 중구 PM10/PM2.5가 ‘나쁨’ 이상으로 올라가면 자동 푸시. “오늘 중구 미세먼지 나쁨 😷 마스크 챙겨”처럼. 아침 브리핑에도 “오늘 마스크 필요/불필요” 한 줄.

💡 왜 우리한테: 꼼이 최우선 관심사를 앱이 먼저 챙겨주는 기능. 떨어져 있으니 “마스크 챙겼어?” 잔소리를 앱이 대신.
구현: 이미 있는 weatherHelpers/data.go.kr 대기질 API를 cron에서 임계값 체크 → 초과 시 꼼이(+우댕)에게 FCM. 중복 방지 위해 하루 1회 상태 기억(dailyStats 패턴 재사용).

👋 상대 접속 알림 우선 높음난이도 ★

“꼼이가 방금 접속했어 💚” — 상대가 앱에 들어오면(오랜만이면) 조용한 알림. 지금은 앱을 열어야만 접속 상태를 볼 수 있는데, 이걸 먼저 알려주면 자연스럽게 “나도 들어가 볼까”가 됩니다.

구현: presence touchPresence 기록 시, 상대가 최근 N분 비접속이었다면 cron/Cloud Function이 감지해 FCM. 스팸 방지로 30분 쿨다운.

✏️ 낙서·하트·댓글 알림 우선 높음난이도 ★

상대가 낙서장에 새 낙서를 남기거나, 내 낙서에 하트/댓글을 달면 알림. 방금 만든 하트·댓글 기능(build 3)과 바로 연결돼요. “꼼이가 낙서에 하트를 눌렀어 ❤️”.

구현: RTDB canvas/{page}/react·strokes 변화에 Cloud Function 트리거 → 상대에게 FCM. 딥링크 kkommorning://canvas로 바로 이동.

🌅 아침·밤 인사 & 기념일 알림 우선 중간난이도 ★

매일 아침 “꼼모닝 ☀️ 오늘 서울 맑음, 미세먼지 좋음, 일정 1개”. 밤엔 “잘 자 🌙”. 그리고 D-day 기념(매월 28일·100일·1주년)에 축하 푸시. 기념일을 앱이 절대 안 까먹게.

구현: 기존 아침 cron 확장 + 날짜 계산(D-day 2023-09-28 기준). 리치 푸시로 날씨 아이콘·D-day 숫자 포함.

B. 잠금화면 · 위젯 — 안 열어도 보이게

🏝️ 라이브 액티비티 · 다이나믹 아일랜드 우선 높음난이도 ★★★

둘 다 접속 중일 때 잠금화면과 다이나믹 아일랜드에 실시간 위젯이 떠요. “지금 같이 접속 중 💚”, 상대가 낙서 중이면 “꼼이가 그리는 중 ✏️”, 하트를 보내면 아일랜드에서 하트가 통통. 앱을 안 열어도 연결감이 유지되는, 네이티브에서만 가능한 기능.

💡 왜 우리한테: 떨어져 살아도 화면 켤 때마다 “지금 같이 있네”가 보이는 게 이 앱의 핵심 정서예요.
구현: ActivityKit + WidgetKit. 접속 시작 시 Live Activity 시작, presence/live 변화를 APNs push-to-start·update로 갱신(백그라운드에서도 최신). 종료 조건은 90초 무접속.

💗 인터랙티브 위젯 — 위젯에서 하트 보내기 우선 높음난이도 ★★

홈 위젯의 하트 버튼을 탭하면 앱을 안 열고도 상대에게 하트 발송(라이브 하트로 연결). iOS 17 App Intents로 위젯이 직접 동작. “보고 싶다” 한 번을 홈 화면에서 즉시.

구현: AppIntent + Button(intent:). 인텐트가 App Group을 통해 RTDB로 라이브 하트 ping 기록. 성공 시 위젯 타임라인 리로드로 “보냈어 💌”.

🖼️ 낙서 썸네일 위젯 (4×4) 우선 중간난이도 ★★

큰 위젯에 최근 낙서를 실제로 그려서 보여주기. 홈 화면에 상대의 최근 낙서가 액자처럼 걸려 있는 느낌. (지금 위젯은 텍스트 위주라 이걸로 감성 UP.)

구현: 낙서 획(정규화 좌표)을 App Group에 저장 → 위젯에서 SwiftUI Path/Canvas로 렌더(웹 DoodleThumb과 동일 로직). 이미 구조는 준비됨(deferred로 미룬 항목).

🕰️ StandBy · 잠금화면 · 제어센터 위젯 우선 낮음난이도 ★★

충전하며 가로로 두면 탁상시계처럼 접속 상태·D-day 표시(StandBy). 잠금화면 위젯(원형·인라인)은 일부 있으니 확장. iOS 18 제어센터 위젯으로 “하트 보내기”를 제어센터에서.

구현: WidgetFamily에 .systemLarge(StandBy는 자동)·.accessory* 이미 일부 대응 → 레이아웃만 추가. 제어센터는 ControlWidget(iOS 18).

C. 낙서장 — 네이티브급 감성

👆 상대 펜 커서 실시간 생중계 우선 높음난이도 ★★

지금은 상대가 획을 다 그려야 보이는데, 펜 끝 위치를 실시간으로 내 화면에 점/이름표로 표시. “꼼이가 지금 여기 그리는 중”이 손끝으로 보임 — 같이 그리는 맛이 확 살아납니다.

구현: 이미 있는 publishLive(live 노드) 확장 — 그리는 중 좌표를 초당 몇 번 write, 상대는 subscribeLive로 커서 렌더. 기반 절반은 완성.

🎨 Apple Pencil 필압·기울기 + 재생 우선 중간난이도 ★★

펜슬 필압·기울기로 자연스러운 붓 느낌(지금은 근사치). 낙서 완성 후 획 순서대로 리플레이 재생 — 상대가 어떻게 그렸는지 손글씨 편지처럼 다시 봄.

구현: UITouch.force/altitudeAngle를 point의 p에 반영(스키마 이미 {x,y,p} 지원). 리플레이는 저장된 point 배열을 타이머로 순차 draw.

🌸 스티커·사진·배경 템플릿 우선 중간난이도 ★★

낙서에 포차코 스티커·이모지 도장 찍기, 사진 붙이기(둘이 찍은 사진 위에 낙서), 편지지·격자·점선 배경 템플릿. 편지에 쓰는 움직이는 스티커 자산을 낙서장에도 재사용.

구현: 스티커/사진을 별도 오브젝트 레이어로 RTDB에 저장(위치·크기·회전). 배경은 canvas/{page}/meta에 템플릿 종류 추가.

📳 낙서 햅틱 + 사운드 우선 중간난이도 ★

그릴 때 펜 사각사각 촉감(Core Haptics), 하트 받으면 통통 진동, 새 낙서 도착 시 은은한 효과음. 작지만 “살아있는 앱” 느낌을 크게 올려줍니다.

구현: CoreHaptics / UIImpactFeedbackGenerator. 라이브 하트 수신·낙서 커밋 이벤트에 연결. 반나절이면 체감.

D. 멀리 있어도 — 위치·시리·워치

📍 도착 알림 (Geofence) 우선 중간난이도 ★★★

상대가 집(호평동)·회사(중구)에 도착하면 나한테 조용한 알림 — “꼼이 집 도착 🏠”. 떨어져 사는 커플에게 “잘 들어갔나”를 자동으로. 정확 위치가 아니라 ‘도착했다’ 신호만 공유(프라이버시 안전).

💡 왜 우리한테: 호평동↔중구로 떨어져 있으니 “도착했어?” 카톡을 앱이 대신. 위치 좌표는 공유 안 함, 도착 이벤트만.
구현: CLLocationManager region monitoring(등록한 2~3곳). 진입 시 로컬로 감지→RTDB에 arrived 이벤트만 write→상대 FCM. “Always” 위치 권한 필요(설명 UI 중요).

🗣️ Siri · 단축어 · App Intents 우선 낮음난이도 ★★

“시리야, 꼼이 접속했어?” → 접속 상태 답변. “꼼이한테 하트” → 하트 발송. 단축어로 홈 화면 아이콘·자동화(예: 매일 밤 9시 “굿나잇 하트”)도 가능.

구현: AppIntents 프레임워크(위젯 인텐트와 공유). presence 조회 인텐트 + 하트 발송 인텐트를 노출.

⌚ Apple Watch 앱 우선 낮음난이도 ★★★

손목에서 접속 상태·D-day 컴플리케이션, 하트 보내기, 낙서/하트 알림 받기. 시계 문자판에 “D+○○○ 💚” 상시 표시. 폰을 안 꺼내도 연결되는 최소 접점.

구현: watchOS 타깃 + WatchConnectivity/독립 네트워크. 컴플리케이션은 WidgetKit 공유 코드 재사용 가능.

E. 소통 · 추억 (네이티브 이점 있는 것만)

📷 오늘의 사진 · 라이브포토 위젯 우선 중간난이도 ★★

하루 한 장 “오늘 나”를 서로에게. 위젯에 상대의 오늘 사진이 뜨고, 탭하면 슬라이드쇼. 네이티브 카메라·PhotosPicker로 바로 찍어 올리고, 라이브포토도 가능.

구현: PhotosUI picker → Firebase Storage 업로드 → 위젯이 App Group 캐시로 표시. 추억(memories) 기능과 연계.

🎙️ 음성 쪽지 우선 낮음난이도 ★★

짧은 목소리 메시지를 낙서/편지에 첨부. 글보다 목소리가 좋을 때가 있죠. 잠들기 전 “잘 자” 한마디.

구현: AVAudioRecorder → Storage 업로드 → 상대에게 알림. 낙서장 오브젝트 또는 편지 첨부로.

❓ 오늘의 질문 (커플 문답) 우선 낮음난이도 ★

매일 질문 하나(“요즘 제일 고마웠던 순간?”) → 둘 다 답하면 서로 공개. 알림으로 매일 챙겨주면 대화가 이어져요. (웹으로도 가능하지만 알림이 있어야 습관이 됨 → 네이티브 시너지.)

구현: 질문 풀 + 날짜 시드 선택, RTDB 답변 저장, 아침 푸시로 유도. 가벼운 도메인 하나 추가.

F. 밑바탕 (탄탄하게)

📡 오프라인 지원 · 백그라운드 새로고침 우선 중간난이도 ★★

지하철·비행기에서도 낙서장이 열리고, 연결되면 자동 동기화. 위젯·라이브 액티비티를 백그라운드에서 주기적 갱신해 항상 최신.

구현: RTDB persistence(오프라인 캐시) + BGAppRefreshTask. 지금은 웹뷰 기반이라, 낙서장 네이티브 부분부터 오프라인 큐 적용.

🔐 보안·백업 마감 우선 낮음난이도 ★

Face ID는 이미 있음 ✅. 여기에 iCloud 자동 백업(낙서·추억), 스크린샷/화면 녹화 시 흐림 옵션 등 둘만의 공간을 더 안전하게.

구현: 데이터는 이미 RTDB 클라우드(안전). 민감 화면에 isSecureTextEntry 트릭/블러 오버레이 추가.

🔗 공유시트 · Universal Links 우선 낮음난이도 ★

다른 앱에서 사진·글을 꼼모닝으로 공유(인스타 사진 → 낙서 배경으로). 링크를 누르면 웹 대신 앱으로 바로(Universal Links).

구현: Share Extension 타깃 + apple-app-site-association 파일(kkommorning-v2.vercel.app). 딥링크는 이미 kkommorning:// 있음.

6 기술 메모

공통 준비물

· APNs 인증키(.p8) — Apple Developer에서 발급 → Firebase 콘솔에 등록(FCM↔APNs 연결). 푸시 계열 전부의 전제.

· Capabilities — Push Notifications, Background Modes(Remote notifications, Background fetch), App Groups(있음 ✅), 위치는 Location Updates.

· 서버 발송 — 이미 있는 Vercel cron(아침 웹푸시)에 FCM Admin SDK 추가. 토큰은 RTDB tokens/{user}.

· Cloud Functions(선택) — RTDB 변화(낙서·하트) 실시간 트리거 알림엔 Firebase Functions가 편함. cron으로도 근사 가능.

재사용 가능한 자산(이미 있음)

· 정규화 낙서 렌더 로직(웹 DoodleThumb) → 위젯·워치 그대로.

· publishLive/subscribeLive → 펜 커서 생중계 절반.

· App Group·WidgetBridge → 인터랙티브 위젯·라이브 액티비티 데이터 통로.

· 시계 오차 보정(serverNow) → 위젯·라이브 액티비티 시간 정확.

· 딥링크 kkommorning:// → 알림 탭 시 해당 화면 이동 준비 완료.
